# Полярная звезда — визуальная библия

Для ведущего и для новой графики: как герои и места выглядят **на готовом арте**
(`art_batch2/polar_lithograph`). Стиль `polar_lithograph`: литография в индиго и ледяном голубом,
иней на сукне и мехе, тёплые точки фонарей. Поясные портреты.

Ведущий описывает то, что игрок видит на портрете текущей партии. Отметка **⚠** значит, что портрет
расходится с каноном (`polar_star.md`, §3) по полу или возрасту; канонный облик нужно доделать вторым вариантом
(`NIGHT_CASE_OWNER_DIRECTION.md` §8). В этом мире расхождений больше всего.

## Места

У каждого места четыре версии по времени суток. Арт — вертикальная литография.

| id | Что видно |
| --- | --- |
| `cargo_hold` | Трюм: ящики и мешки в инее, фонарь, трап наверх |
| `engine_room` | Машинное отделение: маховики, котёл с огнём, решётчатый пол, пар |
| `galley` | Камбуз: длинный стол, плита, посуда, иллюминатор |
| `ice_scout_route` | Ледяная тропа разведки: флажок, следы, трещины, горы |
| `radio_shack` | Радиорубка: дверь в инее, в окне радист у аппарата |
| `ship_bridge` | Мостик: штурвал, окна на льды, ящики, фонарь |
| `shore_camp` | Береговой лагерь: палатки на снегу, дым, торосы |
| `sick_bay` | Лазарет: койки с клетчатыми одеялами, шкаф, стол, иллюминатор |
