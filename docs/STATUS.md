2. **Полный gate и CI.** Быстрые проверки зелёные, но Docker/PostgreSQL, миграции, restore и CI в этой сессии не подтверждены.
3. **Самодостаточность репозитория (T2).** Часть нужных файлов и арт-материалов вне git; чистый checkout теряет контекст.
4. **Платформенный долг.** По аудиту T5, T6, T8, T9, T10 не закрыты: единая граница origin/CSRF, `Principal`, контракт модуля, Telegram-адаптер и удаление легаси.

6. **Проверка статусов задач.** Часть шапок задач расходится с git; перед изменением статуса нужна сверка с кодом и тестами.

## 6. Правило обновления статуса

- Статус меняется только по свидетельству: команда, тест, git-ревизия, миграция или пользовательский сценарий.
- Нельзя ставить `done` по обзорному документу, старому отчёту или сообщению коммита.
- Если документ расходится с кодом, приоритет у кода и свежих проверок; расхождение записывается, а не замалчивается.
- Этот файл не дублирует детали задач: он ссылается на них и фиксирует только здоровье, блокеры и границы проверенного.
