# Интеграция «Alchemia» с Morning Quiz

## Что это теперь

«Alchemia — мастерская открытий»: 431 элемент из четырёх стихий, 1035 однозначных
рецептов, 431 иллюстрация (421 файл в illustrations/, остальные строит build_art.py), 10 категорий, 33 главы,
42 достижения, плюс кампании и экспедиции (`journey.js`). Игра не ходит в сеть, не
знает про Telegram и хранит прогресс в `localStorage`.

## Источник правды и сборка

- `data.json` — канон контента (элементы, рецепты, категории, главы, кампании,
  достижения). `build_data.py` его только валидирует и **никогда не перезаписывает**.
- `verify_content.py` — валидатор: достижимость каждого элемента от базовых стихий,
  отсутствие дублей пар и бесполезных рецептов, покрытие иллюстрациями.
- `illustrations/*.svg` (по одному файлу на элемент) → `build_art.py` собирает `art.svg`.
- `build.py` вшивает `shell.html` + `style.css` + `art.svg` + `data.json` + `game.js`
  (+ `journey.js`) в один автономный `index.html` и пишет `CONTENT_REPORT.json`
  с sha256 артефакта.

```bash
cd minigames/alchemia-1.0
PYTHONUTF8=1 python build.py            # index.html (в .gitignore) + CONTENT_REPORT.json
cp index.html ../../web/mini_client/alchemy.html
```

Проверенная сборка: **850 034 байта, sha256
`18acfb4233ef3950f8df57717f460357a3d4219c5473e0d19e3c809b44ec0e86`**,
431 элемент, 1035 рецептов, 431 различный SVG. Сборка воспроизводится байт в байт
(сверяли с присланным пакетом; отличия — наш мост синхронизации `sync.js` и правки
для телефона: подъём элемента долгим нажатием и экран «Путь алхимика»).
Переводы строк закреплены в `.gitattributes` (включая `*.svg`), иначе хеш
разъезжается между Windows и Linux.

## Как встроена в приложение

- Собранная страница коммитится как `web/mini_client/alchemy.html` и отдаётся по
  `GET /app/alchemy` (`web/mini_app.py`, маршрут объявлен раньше `/app/{asset}`).
- Сырой `/app/alchemy.html` закрыт (404); CSP одиночной страницы:
  `default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; …`.
- Плитка «Атлас маленьких чудес» на главной мини-аппа (`web/mini_client/app.js`).
- Страница автономна по ресурсам: 0 внешних скриптов и ссылок. Сеть обращается
  только к нашим API для sync и craft (`connect-src 'self'`), см. ниже; текущий размер gzip проверяется сборкой.

## Синхронизация прогресса (механики)

`sync.js` вшивается в сборку отдельным маркером `/*__SYNC__*/` и при запуске внутри
мини-аппа отправляет локальную сводку на `POST /api/mini/alchemy/sync`; она
сохраняется для восстановления, но не подтверждает рейтинг и не начисляет наград.
Успешное смешивание отдельно отправляется как команда на
`POST /api/mini/alchemy/craft`: сервер сверяет пару с каталогом, проверяет
подтверждённые ингредиенты, однократно начисляет награду и обновляет рейтинг.
Старые открытия остаются в коллекции, но начинают считаться рейтинговыми только
после серверно подтверждённого получения. Для гостя и offline-игры коллекция
продолжает работать без рейтинговых наград.
Сессия Mini App передаётся странице через same-origin `HttpOnly` cookie; секрет
не попадает в URL, `localStorage` или `sessionStorage`. Записи из standalone HTML
без активной сессии не отправляются на сервер.

Правила механик описаны в `docs/MINI_APP_ALCHEMY.md`. Тест
`test_alchemia_atlas_is_served_as_self_contained_mini_app_page` проверяет, что
внешних ссылок нет, а оба сетевых маршрута принадлежат нашему API.

## Совместимость сохранений

Новый движок пишет в `localStorage` стабильный ключ `alchemia.atlas` (схема версии 2)
и при пустом основном ключе **сливает** прогресс из legacy-ключей
`alchemia.atlas.v5 … v1` (наш прежний `alchemia.atlas.v1` там есть) и из самого
первого `elementAlchemyDiscovered`. Открытые элементы, записанные рецепты, попытки
и избранное переносятся автоматически — прогресс игроков не теряется.

## Телефон: жесты и «Путь алхимика»

На узком экране панель `.journey` скрыта вёрсткой (`@media(max-width:1030px)` оставлял
только полоску прогресса), поэтому цели, главы и статистика открываются отдельным
экраном по кнопке прогресса над мастерской (`data-action="path"`, класс `path-open`
на `body`); главы и эпохи — кнопкой внутри этого экрана.

Элемент из коллекции на тач-экране поднимается **долгим нажатием** (260 мс; сдвиг
больше 8 px считается прокруткой списка). Сразу тянуть нельзя: иначе страница не
прокручивается, и именно поэтому раньше на телефоне работал только тап. Тап
по-прежнему смешивает, свайп по-прежнему прокручивает.

## Синхронизация между устройствами (как это работает теперь)

Игра читает сохранение **только при старте** и сразу пишет своё состояние
(`persist()` при загрузке). Поэтому моста в `localStorage` недостаточно: он бы
записал серверный прогресс, а игра следом затёрла бы его своим. Именно так у живого
игрока получались «разные аккаунты» на ПК и телефоне.

Правильный путь: страница отдаёт наружу `window.Alchemia.applyRemoteState(remote)`
(в `game.js`), он вливает серверные открытия в **живое** состояние игры, дорисовывает
атлас и только потом сохраняет. Мост вызывает его, а `localStorage` обновляет как
страховку; перезагрузка страницы осталась лишь запасным путём для старой версии
страницы. Игрока при этом никуда не выкидывает.

Проверено тестами моста: состояние уходит в живую игру, перезагрузки нет; при
неумении игры принять прогресс срабатывает запасной путь.
