# WeLizard Noir — Changelog

## v1.1 · 2026-10-29

- Исправлены строчные ъ (U+044A) и ы (U+044B) по авторскому SVG; ь (U+044C) сохранён без изменений.
- Изолирована новая правая стойка буквы ы и включена в её контур.
- Обновлены номера элементов для Illustrator SVG и поддержка эллипсов в сборщике.
- Пересобраны TTF, OTF, WOFF, WOFF2, примеры и тестовая таблица глифов.
- Проведена проверка 274 Unicode-кодов; кроме исправленных ъ и ы, метрики других знаков остались неизменными.

## v1.0 · 2026-10-15

- Первая сборка из SVG с латиницей, кириллицей, цифрами и декоративными знаками.
