## 2. Общие проблемы (повторяются у разных моделей)

1. **Модели придумывают правила.** Новые фракции, «NPC под управлением героя»,
   «мёртвый час», события, которые заставляют героев действовать или «открывают
   модуль». Движок умеет только: закрыть место, раскрыть факт, ввести NPC, дать
   ложный след, изменить расписание.
2. **Два типа фабулы на одно дело** и мистические модули (`sanity`,
   `ghost_visions`) в мирах без мистики.
3. **12+ размывается** в мистике и выживании: яд, наркотики (морфий), кровь, приказ
   стрелять, люди в опасности ради сюжета.
4. **Случайные реальные марки и места** («Зингер», «Ласточка», «Карния», похожие на
   реальные названия) и фамилии/инициалы.
5. **Перекос в «самозванца»**: среди лучших завязок 7 из 22 — `impostor`; в газетном
   мире 4 из 5 — подлог. Для плана года нужен баланс типов фабул (CASE_SLATE §6.2).
6. Мелочи: id с кириллицей (`naborщик`), id вместо описаний, лишние «части 4»,
   реплики модели («Привет, Илья», «Жду «дальше»») — в канон не переносить.

## 3. Что делаем дальше (предложение)

1. **Бриф v2** для следующих заказов: закрытый список эффектов событий, запрет новых
   правил и фракций, один тип фабулы на дело, перечень разрешённых модулей для
   мира, расширенный список запретов 12+ (яд, наркотики и медикаменты как сюжет,
   оружие в кадре против людей, похищения, люди в опасности), запрет реальных
   марок даже мимоходом, без фамилий и инициалов, без реплик к пользователю.
2. **Канон мира**: для каждого мира чистовик `worlds/canon/<мир>.md` — только
   принятое из разбора, с правками нарушений. Делается после одобрения Ильи.
3. **Отбор дел**: из ★-завязок собрать план года с балансом фабул, затем писать
   дела по схеме `case.schema.json`.
4. **Арт**: заметки художникам из разборов учесть в очереди Codex (палитры,
   мотивы), где они не противоречат пакетам стиля.
