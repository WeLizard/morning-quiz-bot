# Красильня через «Алхимию» и игра после 50 уровня

- **Статус:** `proposed` — решения владельца по Красильне приняты 2026-11-19 (§6); «Призвания» и Дальние земли — черновик
- **Приоритет:** high (у тестировщицы потолок уровня, новое на ферме больше не открывается)
- **Создана:** 2026-11-19
- **Обновлена:** 2026-11-19
- **Связано:** `FARM_TEXTILE_CHAIN.md`, `FARM_MERCHANT_V2.md`, `FARM_TRIP_MINIGAMES.md`, `FARM_ECONOMY_AUDIT.md`,
  `minigames/alchemia-1.0/INTEGRATION.md`, `domain/alchemy_journey.py`

## 1. Цель

1. Красители перестают быть только товаром Сороки. Ферма получает **Красильню**, которая открывается через
   загадку. Загадку решают в отдельной игре «Алхимия», а сырьё для красителей добывают в дальних поездках.
2. У игрока на 50 уровне (это потолок) появляется долгая цель на ферме. Красильня — первая её ветка.

## 2. Проверенные факты

**Расход на 50 уровне** (ферма тестировщицы в песочнице, данные прочитаны без изменений; 24×24, 120 грядок, 3 га, 4 плантации):
- содержание — **26 тыс. в день**, списывается одним разом при первом сборе;
- кроме него каждый день уходит ещё примерно столько же: старт полей 12,6 тыс. и техника 10–34 тыс.;
- итого 47–97 тыс. в день, без разовых покупок.

Доход скачет:
- 13,7 тыс. (17.11) — 117 тыс. (16.11);
- основа — одна крупная продажа за 77 тыс. и заказы.

Цифры «150 000 в день» в данных не нашлось — нужно уточнить, где игрок её видит (§6, вопрос 1).

## 3. Красильня

### 3.1 Путь игрока

1. **Находка.** В дальней поездке (новые маршруты, §3.3) или у Сороки после первого её красителя игрок находит
   **«Записки красильщика»**: лист с загадкой-стихом, без пометок, где искать ответ. Предмет
   привязан к ферме, продать или подарить его нельзя.
2. **Загадка в «Алхимии».** Стих описывает цепочку смешиваний, но не называет элементы прямо. Пример для индиго: «ягода,
   что ночью синеет, отдаст цвет камню; цвет с водой — и ткань запомнит синеву». Игрок идёт в «Алхимию» и
   проходит новую кампанию **«Записки красильщика»**. На каждый краситель в ней свой этап с целями (`goals`) и
   опытом (`craft`). Этап засчитывает сервер — так же, как печати остальных экспедиций.
3. **Проверка на ферме.** Решение владельца (2026-11-20): Красильня на ферме не показывает записки, их число
   и заголовки, не упоминает Атлас и «Алхимию», не даёт ссылки и подсказки «где искать». Пока ничего не
   выучено, там только короткий атмосферный текст о том, что мастер ушёл без рецептов; выученные рецепты
   появляются списком. Игрок должен сам связать одно с другим. Сервер отдаёт клиенту только выученное.
   Тонкий намёк (решение владельца 2026-11-20): пока рецептов нет, на стене красильни проступает загадка из
   четырёх строк — по строке за каждый новый день, когда игрок заглянул в Красильню (счёт на устройстве).
   Строки описывают четыре стихии, не называя их, Атлас и «Алхимию». Когда сервер выдал печать этапа (`alchemy_stage_claims` того же аккаунта), открывается рецепт красителя
   на ферме. Сверка идёт только на сервере, клиенту не верим.
4. **Сырьё из путешествий.** Рецепт открыт, но нужны растения, которых на ферме нет: вайда для индиго, корень
   марены, рыльца шафрана. Их привозят из новых дальних поездок (§3.3). Позже для вайды и марены можно открыть
   свою грядку (§3.4).
5. **Производство.** Красильня — новое здание, работает по рецептам: `сырьё + протрава (+ вода/соль) → краситель`.
   Красители идут в швейную мастерскую (рецепты уже есть) и в новые заказы.

### 3.2 Три загадки

У каждой загадки своя глава «Записок» и свой этап кампании; рецепт на ферме открывается только своим этапом.

| Краситель | Ферма: сырьё и поездка | «Алхимия»: этап (вариант без новых элементов) |
|---|---|---|
| Индиго | вайда из «Заливных лугов» (поездка 8 ч) | goals: Черника, Пигмент, Краситель; craft: Краситель |
| Марена | корень марены из «Степного кургана» (8 ч, нужна лопата из кузницы/инструмент) | goals: Роза, Корень, Краска, Пигмент; craft: Пигмент |
| Шафран | рыльца шафрана с «Южного каравана» (24 ч, только вместе с соседом, §3.5) | goals: Солнце, Цветок, Краска, Чернила; craft: Чернила |

**Решение владельца: новые элементы.** В «Алхимию» добавляются Индиго, Марена, Шафран и Протрава (квасцы); правый
столбец таблицы выше — только запасной вариант.
- Каждому элементу нужны своя SVG-иллюстрация, рецепты и проверка `verify_content.py`.
- Этапы тогда требуют именно их. Загадка становится настоящей: нового элемента у игрока ещё нет, его надо вывести.
- В варианте без новых элементов игрок, у которого Краситель уже открыт, проходит этап почти сразу.

### 3.3 Дальние поездки

Новый тип маршрута «экспедиция» в тех же двух слотах поездок:
- открывается с L30;
- в дорогу нужен провиант (хлеб, сыр, чай) и плата;
- поездки длинные (8–24 ч): сырьё и редкие находки, среди них «Записки красильщика» и коллекционные вещи;
- мини-игра «пойду сам» — по образцу лесной вылазки (`trip_games.py`), сервер проигрывает ввод;
- проводник сокращает время, как в обычных поездках;
- шанс «Записок» растёт, пока они не выпадут (гарантия на N-й поездке, без бесконечного невезения).

### 3.4 Здание, рецепты, экономика

- **Красильня:**
  - L25 в каталоге, но рецепты в ней открываются только загадками;
  - цена и содержание по закону мастерских (`FARM_TEXTILE_CHAIN.md` §4);
  - улучшения до 3 уровня, как у остальных.
- **Протрава (квасцы):**
  - новый товар из поездки на «Каменный карьер» или из рецепта мастерской: соль + минерал;
  - нужна во всех трёх рецептах красителей — общий узкий ресурс.
- **Цены** считаются по закону мастерских (`_av`). Краситель из Красильни дешевле, чем у Сороки, но требует
  поездок и времени.
- **Сорока остаётся** быстрым путём: продаёт красители, как сейчас. Красильня не ломает её лавку.
- **Свои грядки** для вайды и марены (не шафрана) открываются после 10 поездок за сырьём. Раньше путешествия
  обязательны, потом — по желанию.
- **Новые потребители красителя:**
  - крашеная пряжа;
  - праздничные флаги и ленты для стройки ярмарки;
  - «цветные» заказы обоза;
  - костюмы для праздников (связь с `FARM_FESTIVALS_DESIGN.md`).

### 3.5 Совместность

1. Основной смысл «совместности», по уточнению владельца: игрок проходит загадку в другой игре — «Алхимии».
2. **Решение владельца: шафран — только вдвоём с соседом.**
   - на «Южный караван» за шафраном ходят вдвоём с соседом, одному туда нельзя;
   - каждый вносит половину провианта;
   - добычу делят оба.

   Механика соседей и общих действий уже есть в деревне (`farm_neighbor_pairs`, фонд деревни).
   Чтобы игрок без соседей не застрял, шафранная краска остаётся у Сороки: из Красильни она дешевле, но не обязательна.

## 4. Игра после 50 уровня: «Призвания»

Идея владельца: выбор пути, как сабкласс в Lineage 2. На потолке игрок выбирает **Призвание** — ремесло, в котором
ферма растёт дальше.

### 4.1 Как устроено

- **Выбор на L50.**
  - Призваний шесть (§4.2), основное одно.
  - Опыт после L50 идёт в ранги призвания: 1–10, медленно.
  - За 10-м рангом — звёзды мастерства, так что «больше ничего нет» не наступает.
- **Второе призвание (саб).**
  - Открывается с 5-го ранга основного.
  - Растёт вдвое медленнее и даёт половину бонусов.
  - Поменять основное и второе местами можно раз в сезон.
- **Что дают ранги:**
  - уникальные рецепты и здания;
  - титул над фермой;
  - облик персонажа (фигуры фермера и фермерши уже есть);
  - небольшие постоянные бонусы своей ветки.
- **Зависимость между игроками.**
  - Каждое призвание делает то, что нужно рецептам других: Красильщик — узорные ткани для Трактирщика,
    Селекционер — сорта для повара таверны.
  - Товары ходят через ряды ярмарки и подарки соседям.
  - У игроков на потолке появляется общий рынок, а не шесть одиночных ферм.
- **Экономика.**
  - Призвания почти не печатают монеты: награда — вещи, внешний вид, ускорение.
  - Одна из звёзд мастерства каждой ветки — скидка на содержание. Это ответ на расход больше дохода (§2).

### 4.2 Шесть призваний

| Призвание | Чем занят | Уникальное |
|---|---|---|
| Красильщик-ткач | Красильня (§3), узорные ткани, гобелены | новые цвета из смеси красителей, «Альбом красок», костюмы для фигуры игрока |
| Селекционер | скрещивание сортов на грядках и в саду | головоломка опыления: новые сорта со своими свойствами, семена для соседей |
| Путешественник-картограф | дальние экспедиции (§3.3, §4а) | открывает новые земли раньше, дарит соседям карты (сокращают их поездки) |
| Трактирщик | таверна, банкеты к праздникам | блюда-усилители для соседей и деревни на день праздника |
| Заводчик | породы животных | выставки пород (рейтинг сезона), редкие масти |
| Мастер-строитель | стройки деревни | строит объекты деревни быстрее, мосты и дороги к новым землям |

### 4.3 Что остаётся из прежнего меню

- **Большие заказы мастеров** — еженедельный заказ на деревню; разные его части закрывают разные призвания.
- **Наставничество** — игрок 50 уровня ведёт новичка, награда идёт в ранг призвания.
- **Коллекции:** «Альбом красок», «Журнал экспедиций», журнал пород.

## 4а. Новый контент мира: «Дальние земли»

Мир фермы сейчас — участок, деревня и «За околицей» (лес, озеро, поля, плантации).

**Предложение:** карта Дальних земель, куда ведут экспедиции (§3.3).
- У каждой земли свои ресурсы, житель-проводник, мини-игра, сюжетная цепочка и сезонное событие.
- Земли открываются по очереди: экспедицией, мостом или дорогой из деревни (работа Мастера-строителя), общими
  усилиями деревни.

| Земля | Ресурсы и цепочка | Связь |
|---|---|---|
| Заливные луга | вайда, осока, речной жемчуг | индиго; плетёные корзины |
| Степной курган | корень марены, ковыль, кумыс | марена; кочевой праздник |
| Каменный карьер | квасцы, глина, камень | протрава; гончарная мастерская; материалы для строек деревни |
| Южный караван | шафран, пряности, шёлк-сырец | только вдвоём с соседом; заморские рецепты |
| Морское побережье | соль, водоросли, морская рыба | морская рыбалка (продолжение рыбалки v2); соль для сыров и протравы |
| Горное пастбище | горные травы, сыры, яки (як уже есть) | высокогорные сыры; выставки пород |
| Северная тайга | кедровые орехи, морошка, смола | зимний сезон; Новый год и «Битва с Сантой» |
| Старая обсерватория | метеоритная пыль, звёздные карты | «Алхимия» (мир «Космос»), Звёздная серия редкостей |

Принципы:
- **Земли растут вместе с призваниями.** Например, тропу к обсерватории первым видит Картограф.
- **Сквозные игры.** Через земли связываются «Алхимия» (атлас, загадки), «Ночной город» (тропа уже есть) и праздники.
- **Арт.**
  - Каждая земля — фоновая сцена в стиле «За околицей».
  - Арт делается по навыку `mqb-vector-art`.
  - До подключения в игру — превью владельцу «ферма слева — новое справа».

## 4б. Масштаб: ферма → кооператив → комбинат → агрохолдинг (черновик)

Замысел владельца 2026-11-19: игра про рост от фермы к колхозу, заводам, агрохолдингу и территориям. Мир должен вести
по этому пути, а призвание — определять роль игрока на нём. Ниже — каркас, который это связывает.

### 4б.1 Ступени и уровни

Потолок 50 снимается: уровни идут дальше, по ступеням. Кривая опыта продолжается как сейчас, около +4 % за уровень:
- шаг 50-го уровня — 61,6 тыс. опыта;
- шаг 100-го — около 440 тыс.;
- путь 51→100 — примерно 10 млн опыта, в 10 раз больше пути 1→50. Его уравновешивает новый, более доходный
  контент ступеней. Темп проверяется симулятором (`FARM_ECONOMY_AUDIT.md`).

| Ступень | Уровни | Что это | Новое |
|---|---|---|---|
| Ферма | 1–50 | есть сейчас | — |
| Кооператив (колхоз) | 51–70 | несколько ферм объединяются на равных | общие поля в десятки гектаров, общий машинный двор, общие контракты, равные роли (без правления) |
| Комбинат (завод) | 71–90 | переработка в больших объёмах | заводы-линии: молочный, мукомольный, консервный, текстильный (вырастает из Красильни), сырьё с ферм кооператива |
| Агрохолдинг | 91–100 | территории | карта Дальних земель (§4а) становится картой территорий: освоение регионов, логистика, контракты с городом, дружеские состязания сезонов |

Решение владельца 2026-11-19: уровни до 100. После 100 — звёзды мастерства, как в §4.1; тупика нет.

### 4б.2 Призвание = роль на ступени

Призвание, выбранное на 50 уровне, определяет роль игрока в кооперативе, специализацию его завода и направление
освоения территорий. Шесть призваний §4.2 перекладываются в роли так:

| Призвание | Роль в кооперативе | Свой завод | Территории |
|---|---|---|---|
| Селекционер | агроном | семенная станция, элеватор | поля и плантации регионов |
| Заводчик | зоотехник | молочный и мясной комбинат | пастбища (горы, степь) |
| Красильщик-ткач | лёгкая промышленность | текстильная фабрика | хлопок, лён, шёлк, красильные земли |
| Трактирщик | снабжение и столовая | консервный завод, пищекомбинат | рынки и ярмарки городов |
| Путешественник-картограф | логист | транспортный парк, склады | дороги, караваны, новые регионы |
| Мастер-строитель | инженер | стройкомбинат | мосты, дороги, освоение земель |

Ещё три пути (решение владельца 2026-11-19 — нужны), всего призваний девять:

| Призвание | Роль в кооперативе | Свой завод | Территории |
|---|---|---|---|
| Механизатор | машинный двор | ремонтный завод, техника для полей и заводов | дороги и поля больших регионов |
| Энергетик | мельницы и водяные колёса | электростанция, водяная и ветряная энергия для заводов | реки и ветреные холмы |
| Торговец | обозы и ярмарки | торговый дом, экспорт в город | рынки городов, караваны |

Торговец возит товары жителям и в город, а не скупает их у игроков (§4б.3).

### 4б.3 Принципы

- **Не «Монополия».** Решение владельца 2026-11-19. Никто не управляет другими игроками и не владеет их имуществом:
  - в кооперативе нет председателя, правления и голосований с властью над чужим. Роли равные, каждый вкладывается
    в общие цели, никто не может приказать, наказать или исключить;
  - нельзя купить, поглотить или забрать чужую ферму, завод, землю или долю;
  - территории — общий мир: каждый осваивает свой участок региона, захвата и вытеснения нет;
  - нельзя монополизировать товар. У жителей и в городе любой товар есть всегда, пусть дороже. Цены между
    игроками ограничены, скупки рынка нет;
  - состязания только дружеские: ярмарки, выставки, рейтинги сезона. Награды — внешний вид и титулы, а не
    власть или чужие ресурсы.
- **Без тупика для одиночки** (решение владельца 2026-11-19). Кооператив собирают с живыми соседями. Тот, у кого
  их нет, ведёт его с жителями деревни: они медленнее, зато никто не застревает.
- **Деньги работают.** На ступенях монеты идут в зарплаты, логистику и содержание заводов, а возвращаются через
  контракты. Это ответ на «монеты только уходят» (§2): расход становится вложением.
- **Тон игры прежний.** Мультяшная деревня, жители, юмор. «Агрохолдинг» — это рост мира, а не таблицы. Названия
  ступеней на экране (колхоз, артель, кооператив) выбирает владелец.
- **По частям.** Красильня и экспедиции (§3) — первый кирпич: Красильня станет текстильной фабрикой, экспедиции —
  освоением земель. Каждая ступень — отдельный документ и этапы.

## 5. Реализация (после одобрения)

1. **Экспедиции.**
   - `ROUTES` kind=`expedition` и новые предметы сырья;
   - находка «Записок» со счётчиком гарантии;
   - мини-игра по образцу лесной;
   - тесты паритета JS↔Python.
2. **Кампания в «Алхимии».** Сделано 2026-11-19 (стихи выбраны владельцем из двух вариантов):
   - элементы `mordant` «Протрава» (кислота + глина / минерал), `indigo` «Индиго» (бактерии + лист /
     краситель + ночь), `madder` «Марена» (протрава + корень / краситель + корень), `saffron` «Шафран»
     (цветок + солнце / краситель + золото);
   - экспедиция `paths_camp_dyers` (мир «Эпоха мастерских»): четыре записки-стиха, этапы `dyers_1…dyers_4`;
     печать этапа — то, что мост (п. 3) будет проверять для рецепта красителя на ферме:
     `dyers_1` → протрава, `dyers_2` → индиго, `dyers_3` → марена, `dyers_4` → шафран;
   - режим загадки в клиенте: ответ до открытия показан как «?», подсказок нет — только стих записки
     (`minigames/alchemia-1.0/INTEGRATION.md`);
   - рисунки — `minigames/alchemia-1.0/dyers_art.py`; знак «Записки красильщика»;
   - пересобран `web/mini_client/alchemy.html`, ревизия каталога сменилась (sha256 `data.json`).
3. **Мост ферма ↔ Алхимия.**
   - серверная проверка `AlchemyStageClaim` того же аккаунта при старте рецепта или при открытии Красильни;
   - поле `dyeworks.unlocked[]` в состоянии фермы;
   - гостевой аккаунт без подтверждённых этапов загадку не открывает.
4. **Красильня.** Здание, протрава, рецепты красителей, новые потребители, арт здания (превью «ферма слева — новое справа»
   владельцу до подключения).
5. **Клиент.** Красильня со списком выученных рецептов (без записок, ссылки на Атлас и подсказок), лист «Записки», журнал экспедиций; скриншоты
   на 360/384 с отступом 48 px, днём и ночью.
6. **Призвания** (§4) — отдельный документ с балансом рангов; затем Дальние земли по одной (§4а).
