# ADR-004 — Версионированный файловый банк вопросов локальной админки

- Статус: superseded
- Дата: 2026-08-30
- Задача: MQB-001, первый локальный комплект
- Заменён: [ADR-012](ADR-012-postgresql-question-bank.md)

## Контекст

ADR-001 оставляет статические вопросы в JSON, но старые HTTP-обработчики
перезаписывали целые категории без версии и не ограничивали имена файлов.
Новая админка должна работать с тем же банком, который использует бот.

## Решение

В PG-режиме использовать `/api/bank` и `QuestionBank`: confined paths,
SHA-256 precondition, файловую OS-блокировку, временный файл + `os.replace`,
предыдущие байты в `.history`. Непроверенные legacy API не включать обратно.
Бот перечитывает банк перед новой игрой; активные игры остаются на snapshot.
Preview использует отдельную копию банка, не исходный каталог.

Счётчики использования не являются частью статического банка: они изменяются
в PostgreSQL в транзакции завершения игры под защитой UUID/revision. Память
служит только для выбора категорий/представления, не для bulk-save счётчиков.

## Последствия

Не вводится новая библиотека блокировок. Windows и POSIX поддерживаются;
на этом этапе проверена Windows. История требует места и ручного восстановления.
Установка на сетевую файловую систему не входит в доказательства готовности.
Конкурентное прямое редактирование JSON вне `QuestionBank` не участвует
в блокировке и остаётся запрещённым во время работы редактора.
Для импорта и production нужны отдельная приёмка и разрешение пользователя.
