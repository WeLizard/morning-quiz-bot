# Реестр задач

Реестр содержит проектные задачи, для которых важны архитектурный контекст,
границы и проверяемые критерии готовности. Мелкие локальные исправления можно не
оформлять отдельным документом.

Актуальные правила разработки и выпуска: [DEVELOPMENT](../engineering/DEVELOPMENT.md), [RELEASE_CRITERIA](../engineering/RELEASE_CRITERIA.md), [FARM_CONCEPT](../engineering/FARM_CONCEPT.md) и [AGENTS.md](../../AGENTS.md). Концепт фермы — предложение для обсуждения, не обязательный scope.

## Распределение работы на 2026-11-24

- «Усадьбу» ведёт Клод. Для интерфейса действуют уже принятые макеты. [MQB-012](MQB-012-night-city-full-release.md)
- Codex ведёт отдельные задачи фермы и подготовку выпуска платформы. Ближайшие проверки фермы — кнопки из отчётов №6 и №7 на телефоне в Telegram и действующий цикл винограда и чая. [Плантации](FARM_PLANTATIONS.md)
- Подготовка выпуска начинается с локального прогона PostgreSQL, миграций и восстановления. Отдельно нужна живая приёмка входа, квизов и «Алхимии». [Критерии выпуска](../engineering/RELEASE_CRITERIA.md)
- «Профиль» → «Настройки» хранит часовой пояс аккаунта. В автоматическом режиме берётся пояс устройства. Хаб и игры используют его для личных дат, а «Ночной город» предлагает его организатору нового стола. Зона действующего стола и расписания общего чата берётся из их сохранённых настроек.

Приёмка фермы 2026-11-24 на сборке `fc8bdac`:

- №7, «Покормить лебедей». В браузере песочницы кормление прошло. Списались 3 пшеницы, кнопка стала серой и заблокировалась на 20 минут.
- №6, «Погрузить». В локальном Chromium при 406×612 проверены два ящика с достаточным и недостаточным запасом. Состояния визуально различаются днём и ночью, недоступная кнопка отключена. Погрузка в активном обозе на аккаунте песочницы ещё не проверена.
- №8, «Не могу внести товары». Свежий отчёт относится к форме «Товары в фонд деревни». В `5795372` снят предел в 12 видов, правка выложена в песочницу. Через HTTP и PostgreSQL приняла 287 видов одной командой, подтвердила атомарный отказ и отсутствие повторного списания. Размер исходного взноса в отчёте не указан, повтор сценария тестировщицы остаётся открытым.
- В Telegram Web кнопка бота открыла пустой Mini App с адресом `quizzywizzy.duckdns.org`. Прямой адрес песочницы `quiz.mr-lizard.ru` открыл ферму, аккаунт в браузере 3-го уровня. Приёмка в Telegram на Android, действующий обоз и полка погребка на аккаунте песочницы остаются открыты.

## Известные расхождения статусов

Это не новые статусы и не отметки о завершении, а места, где текст документа
может расходиться с git. Перед изменением статуса нужна проверка.

| Документ | Расхождение |
|---|---|
| [FARM_TEXTILE_CHAIN](FARM_TEXTILE_CHAIN.md) | В одной шапке одновременно «проект» и «реализация» (код в `049bbed`; не сверено, какие этапы приняты) |

Текущая картина и блокеры — в [STATUS](../STATUS.md). Статус `done` ставится
только по выполненным критериям и проверке, а не по обзорному документу.

## Как добавить задачу

1. Скопировать [шаблон](TASK_TEMPLATE.md).
2. Выбрать следующий свободный номер `MQB-NNN`.
3. Заполнить границы, критерии готовности и проверку.
4. Добавить строку в таблицу выше.
5. Если задача принимает долговечное архитектурное решение, создать ADR.

Завершённые и отменённые задачи остаются в каталоге: это сохраняет ссылки и
историю решений. Для них меняется только статус в файле и реестре.
