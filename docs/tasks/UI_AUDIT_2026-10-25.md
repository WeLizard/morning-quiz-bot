## Покрытие и результаты

- В shell обнаружено расхождение токенов: кнопки `.qw-btn` рендерились высотой
  20.75 px с нулевыми внутренними отступами на мобильном входном экране. В
  dev нужные токены уже были; в публичной песочнице обновлён отставший
  `web/shell/qw-tokens.css` и гостевая CTA в `web/mini_client/app.js`.
  Основная кнопка теперь 48 px, вторичные — 44 px. Отдельный публичный
  `gaps --only farm` прошёл: 51 проверка, 0 ошибок.
- Исправлены фильтр рейтинга и пагинация алхимии на широком экране; изменения
  стилей/клиента входят в проверенный набор UI песочницы.
- На фермерском кадре мини-игры Пуха замечено краткое перекрытие тоста Даши,
  около двух секунд в ночном кадре. По имеющимся кадрам это переходное
  перекрытие, не подтверждённый постоянный дефект раскладки; оставить на
  наблюдении при пользовательской приёмке.
- В фото-загадке на экране шириной 390 px маска из 71 символа возникла из
  ошибочного ответа `sha256-…` у импортного изображения. В dev выявлено 1386
  таких включённых строк. Локальная правка seed больше не создаёт их; общий
  выбор вопросов исключает этот точный формат до подсчёта и старта. Строки БД
  не удалены и не изменены. Маска теперь показывает отдельную клетку на букву,
  а подсказка открывает букву в той же клетке. Для корректного ответа «Рись»
  проверены четыре клетки и раскрытие первой; новый кадр лежит в
  `.local/ui-audit-20261025/shell/photo-mask-final/`. PostgreSQL-регрессия
  прошла на изолированной тестовой БД. Три runtime-файла Photo выложены в
  песочницу после резервной копии `photo-mask-20261025-215253`; публичные
  `/app`, `/healthz` и два ассета вернули 200, хэши ассетов совпали.
  Активный старый раунд с ошибочным ответом сам не исправляется. Восстановление
  ответов для 1386 строк требует ручной сверки
  изображений с ответами и отдельного backup-first плана.
