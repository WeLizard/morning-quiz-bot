# 🎮 СПРАВОЧНИК КОМАНД MORNING-QUIZ-BOT

## 📋 Обзор

Данный документ содержит полный список всех доступных команд в боте Morning-Quiz-Bot, включая недавно добавленные функции статистики категорий.

## 🚀 Основные команды

### 🏁 `/quiz` - Начать викторину
**Описание**: Основная команда для запуска викторины
**Использование**: 
- `/quiz` - Викторина с настройками по умолчанию
- `/quiz 5` - Викторина из 5 вопросов
- `/quiz Программирование` - Викторина по конкретной категории
- `/quiz 10 История` - Комбинированный вариант

**Функции**:
- Интерактивное меню настройки
- Выбор количества вопросов
- Выбор категорий (все/случайные/конкретные)
- Настройка интервалов между вопросами
- Анонс викторины

### 📚 `/categories` - Список категорий
**Описание**: Показывает все доступные категории с расширенной статистикой
**Отображает**:
- Название категории
- Количество вопросов в категории
- Статистику использования в текущем чате
- Общее количество использований

**Пример вывода**:
```
📚 Доступные категории вопросов:
- `Программирование` (45) (в чате: 15, всего: 45)
- `История` (32) (в чате: 8, всего: 32)
- `География` (28) (в чате: 0, всего: 28)
```

### 📊 `/category_stats` - Статистика категорий
**Описание**: Детальная статистика использования категорий (НОВАЯ КОМАНДА)
**Отображает**:
- Топ-20 категорий по использованию
- Количество использований и чатов
- Время последнего использования
- Статистику в текущем чате

**Пример вывода**:
```
📊 Глобальная статистика использования категорий:
- `География`: 58 использований, 3 чатов, 1 ч назад
- `Программирование`: 45 использований, 3 чатов, 0 мин назад
- `История`: 32 использований, 3 чатов, 30 мин назад

📱 Статистика в этом чате (123456789):
- `География`: 30 использований (всего: 58)
- `Программирование`: 25 использований (всего: 45)
- `История`: 18 использований (всего: 32)
```

### 🏆 `/top` - Рейтинг чата
**Описание**: Показывает рейтинг пользователей в текущем чате
**Отображает**:
- Топ пользователей по очкам
- Количество очков каждого пользователя
- Позицию в рейтинге

### 🌍 `/globaltop` - Глобальный рейтинг
**Описание**: Показывает глобальный рейтинг всех пользователей
**Отображает**:
- Топ пользователей по глобальным очкам
- Общую статистику по всем чатам

### 📊 `/mystats` - Моя статистика
**Описание**: Показывает личную статистику пользователя
**Отображает**:
- Общий счет
- Количество ответов (правильных/неправильных)
- Заработанные достижения
- Текущую серию правильных ответов
- Максимальную достигнутую серию

### ℹ️ `/help` - Справка
**Описание**: Показывает подробную справку по всем командам
**Содержит**:
- Описание всех доступных команд
- Примеры использования
- Контактную информацию для поддержки

### ↩️ `/cancel` - Отмена
**Описание**: Отменяет текущий диалог или действие
**Используется в**:
- Настройке викторины
- Административных меню
- Любых активных диалогах

## ⚙️ Административные команды

### 🔧 `/adminsettings` - Настройки администратора
**Описание**: Открывает меню административных настроек
**Доступ**: Только администраторы чата

**Описание**: Перезагружает конфигурацию бота
**Доступ**: Только администраторы
**Функции**:

- Перезагрузка настроек
- Обновление вопросов

### 📊 `/chat_stats` - Статистика чата
**Описание**: Показывает статистику викторин в чате
**Доступ**: Администраторы и модераторы
**Отображает**:
- Общую статистику чата
- Активность пользователей
- Эффективность викторин

## 📱 Интерактивные элементы

### 🎯 Кнопки в меню `/quiz`
- **Количество вопросов**: Настройка числа вопросов
- **Категории**: Выбор режима категорий
- **Интервалы**: Настройка времени между вопросами
- **Анонс**: Включение/выключение анонса
- **Сохранить**: Применение настроек
- **Назад**: Возврат в предыдущее меню

### ⚙️ Кнопки в административных меню
- **Категории**: Управление доступными категориями
- **Автоудаление**: Настройка автоматического удаления сообщений
- **Ежедневные викторины**: Настройка расписания
- **Пользователи**: Управление правами доступа

### 🧩 Возможности Bot API 10.2–10.4 (адаптер, 2026-11-19)

#### `/farm` — карточка фермы (только личка с ботом)
Присылает живую карточку своей фермы: монеты, сколько грядок и деревьев готово, таймер до
следующего урожая, заказы с доски. Кнопки «Собрать урожай» и «Сдать» работают прямо в карточке,
«Открыть ферму» запускает Mini App. Команда работает, если включены PostgreSQL и `QW_FARM_ENABLED=1`.
Если фермы ещё нет, бот предлагает открыть её
в приложении. В старых клиентах Telegram видна только подпись карточки.

Адаптер готов и к остальным элементам:
- **Личный ответ по кнопке в группе** (ephemeral): видит только нажавший; при отказе Telegram — всплывающее окно
  только ему. В таких сообщениях запрещены кнопки Mini App и входа (`web_app`, `login_url`).
- **Отключённая кнопка** (`disabled`): показывает, что действие уже выполнено или закрыто.
- **Приватная команда** (`is_ephemeral` в списке команд): в группе её видят только отправитель и бот.
- **Виджет в личке с ботом**: живая карточка внутри сообщения с кнопками, которые отправляют запрос боту.
  В production Telegram — только в личном чате с ботом.

Какие игры и команды получат эти элементы, решает владелец; план — в
`docs/audits/2026-11-16/TELEGRAM_API_GAME_PROPOSALS.md`. Код: `modules/telegram_api_ext.py`, `modules/telegram_widgets.py`.
