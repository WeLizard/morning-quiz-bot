# ADR-014 — Classic как серверный lifecycle с независимой доставкой

- **Статус:** `accepted`
- **Дата:** 2026-09-04
- **Связанные задачи:** MQB-006
- **Заменяет:** часть переходного решения ADR-002 для Classic

## Контекст

Classic-квиз исторически жил одновременно в `BotState`, Telegram poll ID и
адресной строке `quiz_sessions`. Mini App мог показать только отражение Telegram
сообщений и не владел полноценными командами старта, перехода и остановки. Это
мешало продолжать одну игру между интерфейсами и делало Telegram доступность
условием работы Mini App.

## Рассмотренные варианты

### Оставить Telegram ведущим процесса

Минимум изменений, но Mini App остаётся удалённым пультом Telegram; внутренний
раунд появляется только после сетевой отправки, а восстановление зависит от
транспортного снимка.

### Перенести lifecycle в общий application/domain слой

Требует миграции и отдельного delivery binding, зато состояние и правила имеют
одного владельца, а Telegram и HTTP становятся сменными адаптерами.

## Решение

Новые Classic-игры создаются в `games` чистой state machine из `domain/classic.py`.
`ClassicApplicationService` атомарно выполняет start/current/answer/advance/
close/stop, применяет общий scoring и синхронизирует адресные deadlines.

Внутренний `round_id` создаётся до отправки. Связь с внешним Telegram poll ID
хранится отдельно в `game_deliveries`; отправка резервируется до сетевого I/O,
явный `RetryAfter` допускает повтор, а неопределённый результат не повторяется
вслепую. Mini App обращается к application service напрямую и не требует
работающего Telegram worker.

Alembic 0010 переносит существующие Classic-сессии, ответы, poll bindings и
дедлайны из `quiz_sessions`. После миграции Classic не использует
`quiz_sessions` как параллельный runtime source; таблица временно остаётся для
Photo до его отдельного vertical slice.

## Последствия

- Старт, ответ и остановка доступны из обоих интерфейсов с одним состоянием и
  ledger.
- Доступность Telegram больше не блокирует игру в Mini App.
- Telegram delivery и итоги требуют работающего outbox worker, но потеря worker
  не теряет саму игру.
- Legacy BotState lifecycle остаётся только защитной совместимостью на время
  перехода Photo и удаления MiniBridge.

## Проверка решения

- Контейнерный gate выполняет Alembic upgrade/check и 442 теста.
- Отдельный destructive rehearsal поднимает схему 0009, записывает Classic
  snapshot и подтверждает перенос состояния, ответа, poll ID и дедлайна в 0010.
- HTTP smoke запускает, отвечает и останавливает Classic в Mini App без единого
  Telegram-запроса.
- Синтетический Telegram transport проверяет единственное начисление при ответах
  из двух интерфейсов и обязательные `option_persistent_ids` Bot API 9.6+.
