## 🎯 Что это такое?

**Morning Quiz Bot** - это интеллектуальный Telegram-бот для проведения викторин с расширенной системой достижений, статистики и аналитики. Бот предназначен для образовательных целей, развлечения и создания соревновательной атмосферы в чатах.

## ✨ Ключевые возможности

### 🎯 **Система викторин**
- **28+ категорий вопросов** (История, География, Наука, Искусство, Спорт и др.)
- **Гибкие настройки** для каждого чата
- **Автоматические ежедневные викторины** с настраиваемым расписанием
- **Защита от накрутки** с ежедневным сбросом

### 🏆 **Система достижений**
- **Мотивационные сообщения** по глобальным очкам
- **Чатовые ачивки** по очкам в конкретном чате
- **Серии правильных ответов** (Streak System)
- **Уведомления в личные сообщения** о достижениях

### 📊 **Статистика и аналитика**
- **Детальная статистика** по пользователям и чатам
- **Статистика использования категорий** с персистентным хранением
- **Глобальный и локальный рейтинги**
- **Аналитика по сериям правильных ответов**

## 🎯 Система достижений

### 🌟 **Типы ачивок**

#### **1. Мотивационные сообщения** (глобальные)
- **Пороги**: 10, 25, 50, 100, 200, 300, 500, 750, 1000, 1500, 2000, 3000, 5000
- **Логика**: Отправляются при достижении порога глобальных очков
- **Пример**: "🌟 25 очков! Ты уже опытный игрок!"

#### **2. Чатовые ачивки** (локальные)
- **Пороги**: 15, 30, 75, 125, 175, 225, 275, 350, 600, 800, 1200, 1700, 2200, 2700, 3200, 3700, 4200, 4700, 5200
- **Логика**: Отправляются при достижении порога очков в конкретном чате
- **Пример**: "⚡ Ilya повышает уровень — 75 очков в кармане!"

#### **3. Серии правильных ответов** (Streak)
- **Пороги**: 3, 5, 10, 15, 20, 25
- **Логика**: Отправляются при достижении серии правильных ответов подряд
- **Пример**: "🔥 Горячая серия! Ilya подряд 3 правильных ответа!"

### 🎨 **Логика отправки**
- **В групповом чате**: Ачивка приходит в группу + в ЛС пользователя
- **В личном чате**: Ачивка приходит только один раз (без дублирования)
- **Пороги смещены**: Предотвращает спам из одновременных сообщений
