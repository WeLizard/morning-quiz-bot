# Эффекты оранжереи, ярмарки и личные бонусы трактира

Статус: local_verified, без выкладки в бету. Начало: 2026-11-15; проверка: 2026-11-16.
Основание: FARM_VILLAGE_CONSTRUCTION §§3–4.1 и поручение владельца закончить
недоделанные эффекты, проверяя затронутое в Docker.

## Границы

- Рабочая бета `/home/lizard/mqb-rehearsal` — production для реальных игроков.
  В этой задаче там только чтение feedback. Выкладка, рестарты, миграции,
  QA-профили и любые тестовые записи туда не входят.
- Все тестовые состояния, игроки, БД и браузерные профили — в своих Docker-контейнерах.
  Код и отчёты/рендеры — в workspace и на F. Существующие dev/чужие контейнеры не сбрасывать.
- Чужие NightCase/Photo/requirements изменения сохраняются. Отдельная ветка/
  worktree не создаются. Новая SQL-миграция для бонусов не требуется.

## Подтверждённые решения

- Старые взносы и пороги 1000/4000/10000 bp сохраняются; эффекты после done.
  Общие эффекты доступны всем, личные — по собственному вкладу.
- Владелец подтвердил 2026-11-15: ужин по формуле П = max(10, income_ref // 100),
  совокупный лимит бонусов 3% дохода. Не менять цену самого заказа ×0.8.
- Уточнение владельца 2026-11-16: 3% относится к прямым денежным премиям;
  производственное ускорение остаётся постоянным 10%. Общий дневной бюджет
  применяется к игровым премиям house/barn, Олега, денежных village games и ужину.
  Продажа/заказы за товар, возвраты, договорные выигрыши ставок и разовые
  приветственные/referral выплаты относятся к отдельным экономическим потокам.
- Владелец подтвердил: один изменяемый голос почётного строителя за следующий
  московский месяц; при равенстве стабильный порядок id культур; без голосов
  сохраняется прежняя культура, первая — пшеница.
- Первый час ярмарки — час перед обычным открытием, обычное открытие не сдвигается.
  Два дополнительных места используют существующий праздничный ассортимент,
  без новых товаров/цен/дублирования лимитов. Новые шоу не проектируются.

## Результат

1. Оранжерея: культура месяца −10% времени; личное −10% времени заморских;
   дополнительная restricted грядка для существующих заморских; голосование.
   Сортовые культуры не обещаются как доступный контент, пока их нет в каталоге.
2. Трактир: ужин один раз в московские сутки, второй независимый заказ для tier2,
   публичная скамья/эмблема и выбор любимого доступного блюда для tier3.
3. Ярмарка: −10% только на активных праздничных покупках, ранний час tier2,
   публичный флаг tier3, два дополнительных места и инфраструктура сцены/подиума.
   Прошлые праздники, обычная Сорока и торговля между игроками не получают скидку.
4. UI показывает действующую механику и собственную доступность; фразы «эффект
   скоро включится» убираются только для фактически реализованного результата.

## Инварианты реализации

- Чистые правила в village_effects; SQL/shared month state в construction helper.
  Месяцы/голоса — существующие SystemState rows `farm.greenhouse.month:YYYY-MM`,
  schema_version, INSERT ON CONFLICT then FOR UPDATE, whole-payload replacement.
  Farm mirror — кэш, а не источник истины. Итоги закрытого месяца неизменяемы.
- Lock order: все farms → нужные проекты → month keys по возрастанию.
  После month lock нельзя брать чужую farm/project. Sparse carry не создаёт
  неограниченное число записей при долгом отсутствии. Merge будущих голосов:
  main голос сохраняется, secondary удаляется; прошлые итоги не переписываются.
- Посадка использует текущий месяц фактического времени команды после ожидания
  блокировок. Проверка call graph показала: offline settle не сеет растения,
  поэтому отдельная история снапшотов для автопосева не нужна и не загружается.
  Готовые ready_at не пересчитываются. Общая duration крафта/животных не меняется.
  Два −10% перемножаются (0.9 × 0.9).
- Оранжерейная грядка вне земельного лимита, только существующие заморские семена;
  состояние/проекция приватны, plant/harvest fenced циклом и command receipt.
  Merge не теряет семена/созревающий урожай и не удваивает доступную грядку.
- Дневные заказы трактира имеют стабильные slot/order id. Legacy day+item означает
  только slot0; старый receipt засчитывается без ретро-премии. Ужин и сдача блюда
  атомарны, повтор не меняет расход/награду. Merge сохраняет использованные квоты.
- Денежные премии используют один Moscow-day budget в farm aggregate под farm
  lock: фиксированный при первом получении ref/cap, сумма actual paid, by_source.
  Частичная/нулевая выплата не повторяет награду и не снимает результат игры.
  Legacy выплаты дня восстанавливаются из command receipts с дедупликацией
  attempt/run; ledger проверяет полноту покрытия. Его net coins_delta нельзя
  считать премией из-за содержания. При неполном покрытии остаток текущего дня
  консервативно закрывается. Слияние складывает использованные суммы, не cap;
  прошлые монеты не изымаются, при превышении cap остаток равен нулю.
- Цена и доступность ярмарки вычисляются одним helper в buy и owner_view.
  Персональный доступ не попадает в глобальный day cache. Ранняя покупка относится
  к новой occurrence; после полуночи лимиты не сбрасываются второй раз.
- Публичные отличия фильтруют rating_hidden и не раскрывают чужие receipts/голоса.
  Скамья/флаг должны реально отображаться, список имён их не заменяет.
- Арт — только существующий генератор/палитра, сильная модель. Превью владельцу
  до установки нового арта; без нового raster слоя и без полной перерисовки карты.

## Проверка и завершение

Связанные domain/PG/JS suites и целевой пользовательский цикл — только Docker.
Проверить старые вклады/receipts, tiers, два одинаковых блюда в разных слотах,
повторы с разными keys, нехватку/переполнение с rollback, смену суток/месяца,
неизменность ready_at при последующем settle, голос/merge и границы раннего часа.
UI: 375×812, 390×844, 1280×800, день/ночь, крупный план; только viewport + отдельная
прокрутка, fixed панели не выдаются за корректный full-page снимок.
Независимое ревью полного собственного diff; результаты и ограничения ниже.

## Журнал

- Независимая архитектурная проверка до реализации завершена; SystemState-вариант
  отдельно проверен и одобрен с lock/snapshot инвариантами выше.

- На независимом ревью уточнён call graph: offline settle не вызывает посадку.
  Прежнее предположение об историческом автопосеве было ошибочным; лишний
  history loader удаляется, проверяется реальная граница месяца после lock wait.
- Арт: шесть SVG symbols, без новых растровых вложений. Превью показано владельцу
  и одобрено 2026-11-16 с условием «только не поверх деревьев». Установка и
  реальная интеграция выполняются с проверкой отсутствия перекрытия крон.
- Реализация и локальная приёмка этого среза завершены. Родительская C5 целиком
  не закрыта: другие обещания рядов/фонда и будущий контент остаются отдельными.
