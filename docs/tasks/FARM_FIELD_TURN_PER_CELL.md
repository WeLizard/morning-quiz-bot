# Поле, этап 2A: поворот и посев по клеткам

Статус: **исторический этап 2A** (2026-10-28). Новые заходы после 2B/2C идут с
`rules=3`; заходы `rules=2`, открытые на этом этапе, сохраняют описанное ниже
поведение. Полная версия — [FARM_FIELD_SPRAY_AND_TRANSFER](FARM_FIELD_SPRAY_AND_TRANSFER.md).
Канонический свод правил поля — [FARM_FIELD_SPEC](FARM_FIELD_SPEC.md).

## Правила

- Новые заходы получают `run.rules = 2`; заходы без маркера (включая уже
  открытые) сохраняют старые `UDLR` + anchor-sow и работают без `T`.
- Машина стартует с горизонтальной ориентацией `h`; `T` переключает
  `width×1 ↔ 1×width` на месте. Поворот допустим только если новый footprint
  помещается в поле и не задевает камни. `T` входит в маршрут, лимит и честное
  время, но не покрывает клетки и не считается новым визитом.
- Рабочая область и знаменатель охвата для 2A остаются горизонтально
  достижимыми клетками (как в этапе 1). Поворот нужен для проезда в узких
  местах; клетки вне горизонтальной области остаются «не в счёт», как сейчас.
- Посев по клеткам: при любом положении/ориентации засеваются только
  валидные клетки полосы под footprint; повтор — double. Anchor-only остаётся
  для заходов без `rules=2`.
- Выгрузка у фиксированного грузовика для 2A учитывает ориентацию: центр
  машины по X, для `v` это `x + 0.5`.
- `reference_path` остаётся горизонтальным и служит эталоном для обеих версий;
  он не обязан использовать `T`.
