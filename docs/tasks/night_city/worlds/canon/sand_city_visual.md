# Город в песках — визуальная библия

Для ведущего и для новой графики: как герои и места выглядят **на готовом арте**
(`art_batch2/cosmic_engraving`). Стиль `cosmic_engraving`: гравюра пером в песочно-охристой гамме,
плотная штриховка, экспедиционный хаки 1930-х; в местах — нечеловеческие циклопические руины. Фигуры в полный рост.

Ведущий описывает то, что игрок видит на портрете текущей партии. Отметка **⚠** значит, что портрет
расходится с каноном (`sand_city.md`, §3) по полу или возрасту. В этом мире таких расхождений нет:
все портреты совпадают с каноном.

## Места

У каждого места четыре версии по времени суток. Арт — вертикальная гравюра; на фоне всех мест — город
из циклопических башен и арок.

| id | Что видно |
| --- | --- |
| `astronomers_plateau` | Плато астрономов: телескоп на треноге, палатка, ящики, башни вдали |
| `base_camp` | Базовый лагерь: палатки, складной стол, тренога, руины |
| `caravan_outpost` | Стоянка каравана: навес, тюки, грузовик, статуи в скале |
| `excavation_site` | Раскоп: ступенчатые руины, леса, стол с находками |
| `geologists_ridge` | Хребет геологов: скалы, палатка, ящики с образцами |
| `non_human_temple` | Нечеловеческий храм: каменная плита в песке между огромными колоннами |
| `radio_tower` | Радиомачта на растяжках, палатка, ящики с аппаратурой |
| `supply_tent` | Склад-палатка: полки с ящиками и банками, вид на город |
