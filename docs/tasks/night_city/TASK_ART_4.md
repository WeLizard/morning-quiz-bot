# Задача: арт «Ночного города», пункт 4 очереди (2026-10-16)

> Самодостаточное поручение для отдельной сессии (Claude или Codex). Заказчик — владелец проекта.
> Источник требований: [CODEX_ART_QUEUE.md](CODEX_ART_QUEUE.md), пункт 4. При расхождении
> прав файл очереди.

## Цель

Довести арт до полных пакетов: исправления по 3.3 (п. 4.1), шесть миров целиком
(п. 4.2), три новых мира (п. 4.3). Строго по порядку: 4.1 → 4.2 (по одному миру в
указанном порядке) → 4.3.

## Как генерировать

- Генератор: встроенный `image_gen.imagegen` Codex. Если сессия — Claude Code с плагином
  Codex, передать Codex этот файл целиком как задание. Модель и effort записать в
  `notes.txt` так, как их реально подтверждает инструмент; если не подтверждает — честно
  указать «не подтверждено».
- В Git Bash для плагина Codex нужен PATH:
  `export PATH="/c/Program Files/nodejs:/c/Users/Lizard/AppData/Roaming/npm:$PATH"`.

## Куда класть (обязательно)

Генератор сохраняет картинку в `%USERPROFILE%\.codex\generated_images\<сессия>\`.
Сразу после **каждой** генерации скопировать файл (исходник не удалять) в
`docs\tasks\night_city\art_batch2\<пакет>\<группа>\<имя>.png`:

| Что | Путь |
| --- | --- |
| герои | `characters\c_NN_<роль>[_v2].png` |
| места | `locations\<id_места>_<morning\|day\|evening\|night>.png` |
| предметы | `items\i_<лист>_<NN>_<id>.png`, лист целиком — `items\sheet_<лист>.png` |
| интерфейс | `ui\<имя>.png` |
| обложки дел | `covers\case_<№>_<слаг>.png` |

Пакеты: `cosmic_engraving`, `neon_noir`, `prohibition_noir` (4.1 и 4.3);
`eldritch_etching`, `newsprint_noir`, `baroque_mask`, `polar_lithograph`,
`circus_lithograph`, `campus_ink` (4.2).

Сразу после копирования:
1. нормализовать альфу (≥240 → 255, ≤7 → 0);
2. проверить Pillow: размер 1024×1536 (2:3) или 1024×1024 (1:1), RGBA у вырезок и рамок,
   прозрачные углы и края, у рамок середина альфа 0; места, рубашки, обложки, экраны —
   непрозрачные RGB;
3. добавить запись в `art_batch2\<пакет>\manifest.json`: файл, путь к исходнику, промпт,
   sha256, `selected`.

**Если файла нет в `art_batch2`, шаг не сделан.** После каждой группы —
`contact_<группа>.png` на ярко-пурпурном фоне в папке пакета и строка в `notes.txt`.

## Содержание и стиль

- Стиль: `docs\tasks\NIGHT_CITY_ART_DIRECTION.md` §10.1 (блоки стиля пакетов), §10.2
  (состав пакета), правила вырезок версии 2 (без свечения, ореола, виньетки, дымки).
- Эталон стиля пакета: `art_batch2\<пакет>\locations\reference_*.png` — передавать
  референсом в каждый вызов.
- Содержание: каноны `docs\tasks\night_city\worlds\canon\<мир>.md` — места (§2, колонки
  утро/день/вечер/ночь), предметы (§5), завязки дел (§7), палитра (§8). Соответствие
  пакетов и канонов — в CODEX_ART_QUEUE.md, п. 4.2–4.3.
- Без текста на картинках (ни букв, ни цифр), 12+, без крови, оружие только как реквизит
  и не на людей, без реальных людей и брендов, герои без имён.

## Правила

- Ты единственный исполнитель. Перед каждым пакетом прочитать его `notes.txt`; если в
  папке есть файлы моложе 30 минут или записан другой активный исполнитель — не начинать,
  сообщить.
- Готовое не переделывать; замена — новый файл с суффиксом `_v2` (у прежнего в manifest
  `"selected": false`).
- Писать только в `docs\tasks\night_city\art_batch2\`. Ничего не коммитить, не удалять,
  процессы не останавливать (тем более по шаблону имени).
- Проблемный файл — не больше двух переделок, затем отметить и идти дальше.
