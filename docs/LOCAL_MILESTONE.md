## План до одной общей приёмки

1. Закрыть основной административный цикл: банк вопросов, настройки/расписания,
   участники/баллы, фото-метаданные, обзор статистики из PostgreSQL.
2. Устранить сохранение статистики категорий устаревшими снимками памяти.
3. Собрать повторяемый автономный прогон: импорт синтетических JSON,
   сверка значений, обычный/фото-квиз, административные изменения, повторные
   ответы, восстановление состояния и очередь удаления.
4. Пройти полную регрессию, проверку схемы и реальные формы в браузере.
5. Передать PowerShell-команды запуска и отчёт с фактами проверки.

Не останавливаться после отдельных адаптеров: граница передачи — весь этот
комплект, либо внешний блокер, требующий решения пользователя.

## Границы

Telegram заменён тестовым транспортом: проверяется локальная логика, а не
доставка на реальные устройства. Бот с настоящим токеном не запускается.
Админка слушает только loopback. Для демонстрации используется отдельная
постоянная dev-БД на 55433. Исходный банк может заполнить только пустую dev-БД;
дальнейшие чтение и правки идут из PostgreSQL.

Не входят: публикация Mini App, production-миграция и реальные внешние отправки.
PTB 22.8, фото-загрузка, профили, обслуживание, архивы, автономный worker,
тест рассылки и AI-панель добавлены позднее; см. DEV_FEATURES и MQB-002.
Последующее расширение от 2026-08-30: [загрузка новых фото](PHOTO_CATALOG.md)
теперь реализована и проверена локально; это не меняет запрет production.
Также добавлены [профили, журнал, экспорт и название чата](ADMIN_PROFILES.md).
Следующее расширение: [PTB 22.8 и безопасная классика](TELEGRAM_QUIZ_ROADMAP.md)

Также готов [отдельный пользовательский API Mini App](MINI_APP_API.md): вход,

`pwsh -NoProfile -File .\scripts\Start-LocalDevelopment.ps1`.
Старая резервная копия на ПК сохраняется; проверки не доказывают актуальность
данных на сервере и не заменяют будущую миграцию свежего snapshot.

## Запуск на этом ПК

Откройте PowerShell:

```powershell
Set-Location 'C:\Users\Lizard\Projects\morning-quiz-bot'
pwsh -NoProfile -File .\scripts\Start-LocalDevelopment.ps1
```

Панель: <http://127.0.0.1:4184>. Тестовый ключ выводится в консоль:
`local-tests-only-admin-key-0000012345`. Он намеренно публичный и разрешён
только для этой синтетической loopback-демонстрации, не для реальных данных.
Автономный бот запускается явно в разделе «Тестовый бот». Без его запуска
отсутствие свежего подтверждения планировщика ожидаемо.

Единая остановка закрывает панель, Mini App и тестовый Telegram-адаптер.
Постоянная dev-БД по умолчанию сохраняется запущенной:

```powershell
.\scripts\Stop-LocalDevelopment.ps1
```

Для остановки и контейнера используйте `-StopDatabase`; volume, очки и настройки
сохраняются. Не используйте `down -v`: это удалит постоянный volume. Тесты
работают в отдельной `morning_quiz_test` внутри того же контейнера. Основной
проект и сервер не затрагиваются.
Банк вопросов сохраняется в PostgreSQL volume. Исходный `data/questions`
preview не редактирует и после одноразового seed не читает.

## Приёмка одной командой

Приёмка использует отдельную логическую БД и может выполняться рядом с dev:

```powershell
.\scripts\Test-LocalMilestone.ps1
```

Сценарий отказывается работать с сетевой копией проекта и удалённым Docker. Он
пересоздаёт **только** логическую базу `morning_quiz_test` в общем локальном
контейнере, применяет Alembic, проверяет схему, запускает всю регрессию (включая
dump/restore) и проверяет JS. `morning_quiz_dev` и volume не изменяются.
Отчёт: `.local/acceptance/tests.xml` (JUnit).

На новом локальном окружении нужны Docker Desktop (Linux containers) и
PowerShell. Python 3.13, PostgreSQL client, Node.js и зависимости находятся
в dev image:

```powershell
pwsh -NoProfile -File .\scripts\Test-LocalMilestone.ps1
```

Локальный комплект использует **PTB 22.8**. Host Python и глобальные пакеты не
изменяются. Lockfile фиксирует проверенное окружение Python 3.13 внутри image.

Последующий Telegram-этап: **252 теста** (241 regression + 11 acceptance).
Регрессия выполнена в отдельной временной БД, сквозная приёмка — в изолированных
схемах, поэтому открытый preview сохранил свои баллы и каталог. Полный сценарий
`Test-LocalMilestone.ps1` пересоздаёт только `morning_quiz_test`; демо-прогресс

## Банк вопросов

Основной каталог остаётся файловым. Все изменения через новый `/api/bank`
проверяют SHA-256 версии категории, используют межпроцессную файловую блокировку
и атомарную замену файла. До правки/удаления предыдущие байты сохраняются в
`<каталог>/.history/<категория>/<uuid>.json`. История не удаляется автоматически.
Восстановление пока ручное: при остановленной админке выбрать нужную сохранённую
версию и скопировать её в файл категории, затем обновить страницу.

В 63 категориях локального исходника — 6706 записей. Новая строгая проверка
отметила 8 проблемных записей (длинные/повторяющиеся варианты или правильный
ответ вне списка). Они не изменены и не удалены, доступны для исправления
в редакторе; PG runtime выбирает остальные 6698. Импорт/новая правка не
принимают такие записи. Активная игра хранит собственный snapshot вопросов.
