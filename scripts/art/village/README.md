# Генератор карты деревни

`qw_farm/static/village.svg` — мир 2400×1800 с одним встроенным WebP 3200×2400. Этот фон рисует
генератор из этой папки. Здания, деревья, фонари, тени, земля и дороги рисуются собственными функциями
фермы (`qw_farm/static/scene_buildings.js`, методы `FarmScene` из `scene.js`) на канвасе в headless Chromium.
Правки арта деревни делаются здесь, а не накладками поверх готовой картинки
(см. `.agents/skills/mqb-vector-art/SKILL.md`).

## Происхождение

Генератор восстановлен 2026-10-22 по журналу сессии, в которой 2026-10-14…15 нарисован нынешний фон: исходный
`village.js` и все последующие правки воспроизведены по порядку. Восстановленный рендер совпадает с WebP из
`village.svg` до уровня сжатия: средняя разница 1,3 из 255, различаются 0,05 % пикселей (сглаживание).
Из исходника изменены только обёртка (`render()` вместо скрипта страницы), сцена `s` (теперь это настоящий
`FarmScene`, а не копия его методов) и ворота (см. ниже).

## Файлы

| Файл | Что делает |
|---|---|
| `village.js` | Сцена: план в тайлах (дороги, река, площадь, пруд), постройки фермы, реквизит деревни, лес, экспорт координат |
| `common.js` | Объект сцены `s` = неподвижный `FarmScene` и `B` = `scene_buildings.js` с открытыми примитивами |
| `harness.py` | Headless Chromium; отдаёт модули фермы из рабочего дерева, подключает в `scene_buildings.js` записывающие хуки |
| `build_village.py` | Рендер → `world.png`, `village.svg` (WebP q88 m6), `manifest.json`, `hashes.json` |
| `preview.py` | Превью «сейчас ↔ генератор», день и ночь, целиком и кропами, с живыми слоями игры |
| `test_reproducible.py` | Два прогона дают одинаковые байты; хеши равны `reference.json`; координаты живых слоёв равны `app.js` |
| `sheet.js` | Лист всех типов построек фермы (справка при подборе зданий) |

## Команды

```bash
python scripts/art/village/build_village.py                  # -> .local/village-generator/out/
python scripts/art/village/preview.py                        # -> .local/village-generator-preview/
python scripts/art/village/test_reproducible.py
python scripts/art/village/build_village.py --install        # пишет qw_farm/static/village.svg — только после одобрения превью владельцем
```

Нужны Playwright и его Chromium. Используется закреплённый `chromium_headless_shell-*` из
`PLAYWRIGHT_BROWSERS_PATH` (по умолчанию `F:\Caches\ms-playwright`) либо путь из `VILLAGE_CHROMIUM`.
Эталон `reference.json` снят на `chromium_headless_shell-1194`, Pillow 11.3.0, libwebp 1.5.0. На других
версиях тест проверяет только равенство двух прогонов и сообщает о расхождении с эталоном.

## Неподвижный фон и живые слои

В фон запекается только неподвижное. Всё, что движется или нажимается, — отдельные слои игры (`app.js`, `style.css`),
которые ставятся по координатам из этого же рендера (`manifest.json`, единицы мира 2400×1800):

- дым труб — `smoke` (= `VILLAGE_SMOKE`); в фоне трубы без дыма: хук `smoke()` записывает точку и не рисует;
- окна и фонари ночью — `lights` (= `VILLAGE_LIGHTS`): хуки `winY`/`winX` записывают каждое окно;
- крылья ветряной мельницы — `sails` (элемент `.vfx-sails`); в фоне только башня;
- водяное колесо — `wheel_hub` (= ступица `VILLAGE_WHEEL_SVG`, 731/555); в фоне ось, жёлоб, слив и пена, лопасти — живой SVG-слой;
- табличка «Ферма» — кнопка `.village-gate`; в фоне арка (столбы, дуга, цепи, фонарь), доска — `gate_board.svg`.

Ворота — `gate.js`, в стиле таблички фермы (`FarmScene.welcomeSign`): тёмные столбы с острыми навершиями, трава у
подножия, фонарь на кронштейне. Арка запекается в фон. Доску рисует сама `FarmScene.signBoard` в плоскости арки, но
в записывающий контекст `svg_ctx.js`, поэтому она получается векторным SVG для кнопки: дневной и ночной варианты
(ночью, как на ферме, доска светлее тонировки), прозрачная зона нажатия `vg-hit` = контур доски с полями 4 единицы.
Положение и размер кнопки — `manifest.json → gate_board`. Превью ворот: `preview_gate.py` (375 и 1280, день, ночь, наведение).
Для подключения в игру нужно заменить `VILLAGE_GATE_SIGN`/`VILLAGE_GATE_BOARD` в `app.js` на `gate_board.svg` и его рамку
и добавить CSS из `preview_gate.GEN_CSS` (кнопка `pointer-events:none`, нажимается только `vg-hit`; день/ночь).

## Как править арт

- Новое здание: `building('<тип фермы>', x, y, w, h)` в разделе плана `village.js`; координаты в тайлах фермы.
  Жителю — `spot('<имя>', x, y)` у двери. Проверка `problems` не даёт поставить объект на дорогу или в воду.
- Предмет, которого нет на ферме, рисуй примитивами `B.*` (`box`, `gableRoof`, `cyl`, `Q`, `L`, `E`) и цветами
  фермы, по образцу уже имеющихся (`well`, `stall`, `bench`, `pier`, `bearDen`).
- После правки: `build_village.py` → `preview.py` → показать владельцу. После одобрения: `--install`, перенести изменившиеся
  координаты из `manifest.json` в `app.js`, обновить `reference.json`.
