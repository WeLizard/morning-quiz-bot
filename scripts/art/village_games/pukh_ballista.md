# Сцена «Энергетос-баллиста» — превью

Статус: **не подключена, ожидает просмотра и одобрения владельца**.

`pukh_ballista.js` — редактируемый источник чистого SVG; использует `FarmScene.poly`,
`line`, `ellipse` через общий записывающий контекст генератора деревни. Палитра,
светлая/теневая грань и фигура Пуха опираются на `scene_buildings.js`, сцену Олега
и `scripts/art/village/crew.js`. Растров в игровом ассете нет. PNG — только кадры
для сравнения; слева действительно рисуются функции исходной фермы.

Сборка (Playwright и закреплённый Chromium генератора деревни):

```powershell
$env:TEMP='F:/Temp'
$env:TMP='F:/Temp'
$env:PYTHONPYCACHEPREFIX='F:/Caches/pycache'
$env:PLAYWRIGHT_BROWSERS_PATH='F:/Caches/ms-playwright'
python scripts/art/village_games/pukh_ballista.py
```

Результаты: `.local/pukh-ballista-preview-20261025/` на физическом F:.
Сборщик не имеет режима установки. Он проверяет XML, уникальность ID, отсутствие
`image`/растров/фильтров и равенство двух сборок. Пишет SVG день/ночь, сравнения
375×812, 390×844, 1280×800 и отдельные крупные планы 1000×600.

## Контракт координат

Мир 1000×600. Старт снаряда `(60,500)`. Горизонтальная поверхность навеса:
`x=420..560`, `y=360`. Центры окон, нумерация с нуля:
`(270,330)`, `(430,250)`, `(600,200)`, `(760,300)`, `(900,400)`; радиус цели 36.
Внутри каждого открытого окна квадрат 72×72; круг цели целиком в нём.

Живые слои имеют отдельные ID:

- `pb-window-0..4` — рамка, створки и внутренняя область; `pb-target-0..4` —
  невидимые круги с точными координатами для проверки/подсветки активной цели.
- `pb-projectile` — банка со стартовым центром `(60,500)`; клиент перемещает группу
  относительно старта, скрывает при попадании и возвращает на следующий ход.
- `pb-vane` — стрелка флюгера, центр `(490,323)`; зеркалится только стрелка.
- `pb-paw` — лапа Пуха; `pb-slingshot` — неподвижная рогатка.

Фон не содержит траектории, счётчиков или выделения активной цели. Это задача
клиента по серверному плану. Отдельные дневная/ночная палитры не меняют обычную
графику фермы и не связаны с настройкой контрастного режима аккаунта.

После одобрения арта требуется интеграционная проверка в настоящем игровом
экране. Кадры этой папки подтверждают геометрию предложения, а не готовность игры.
