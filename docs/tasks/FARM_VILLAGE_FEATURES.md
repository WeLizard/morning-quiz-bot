Статус: черновик предложений для согласования с владельцем (Илья).
Уже есть: жители и их заказы, ратуша (фонд, содержание, декор), сезонный праздник.

Ниже есть два вида пунктов:

- **Сделано (клиент)** — только вид и переходы в разделы, которые уже есть. Экономика и сервер не меняются.
- **Предложение** — нужны новые серверные правила или награды. Ничего из этого не реализовано, пока Илья не согласует.

## 0. Сделано сейчас (только клиент, `qw_farm/static/app.js`, деревенский блок)

| Что | Как работает | Риск для баланса |
|---|---|---|
| Таблички мест на зданиях | Доска заказов → «Заказы». Почта → «Соседи» (подарки, приглашения). Рынок → «Склад» (продажа). Мастерская Крота → «Мастерские». Библиотека (школа) → «Журнал». Причал → «Озеро». Игрок сначала идёт к табличке, потом открывается раздел (`VILLAGE_PLACES`). | Нет |
| Гости дня | Два гостя в день. Выбираются детерминированно по московской дате (`villageVisitorsToday`), поэтому все видят одних и тех же. По воскресеньям — Богатырь (раз в 7 дней). Есть фигурка с облачком и лист с репликой. Кнопка ведёт в существующий раздел: склад, озеро, лес, журнал, постройки, соседи, находки. | Нет: награды не выдаются |

Технически: всё лежит в статичном слое, который строится один раз вместе с миром. Анимации — только transform/opacity, вне экрана ставятся на паузу (`.va` + IntersectionObserver). Одновременно не больше двух гостей.

## 1. Приходящие жители (предложение)

Расписание общее для всей фермы: `seed = день по Москве + сезон`. Сервер отдаёт `village.visitors = [{id, until}]`. Тогда клиент не гадает, и все игроки фермы видят одно и то же.

| Гость | Характер, реплика | Тип заданий | Когда приходит |
|---|---|---|---|
| Странствующий торговец | Хитрый, весёлый: «Сторгуемся?» | Обмен: N товаров на редкие семена или декор | 2 раза в неделю |
| Рыбак Сом | Неторопливый | Сдать улов, сварить уху | После дождя / в выходные |
| Лесник Бор | Строгий, заботливый | Ягоды, грибы, хворост | Летом и осенью |
| Сказитель | Говорит загадками | Вопросы-викторины (как вопрос Филиныча) | Раз в неделю, вечером |
| Плотник Тёс | Деловой | Материалы для строек деревни (раздел 3) | Пока идёт стройка |
| Путница Веся | Любопытная | Отнести письмо или посылку соседу | Ежедневно, редко |
| Богатырь | Немногословный, тёмное славянское фэнтези, «камень на распутье» | Цепочка «Три дороги» на 3–7 дней с выбором пути | Раз в сезон |

Данные: `VISITORS = {id: {name, lines[], quest_pool[], schedule}}` в каталоге. Состояние гостя на сервере не хранится, только выполненные задания.

## 2. Задания жителей (предложение, нужен баланс)

Виды: ежедневные (1–2 шт.), недельные (цепочка из 3 шагов), особые (гость или праздник).

Схема:

```
village_quests: [{id, giver, kind: daily|weekly|special, steps:[{needs:{item:n}} | {visit:'npc'} | {game:'quiz'}],
                  reward:{coins, xp, rep:{npc:n}, decor?}, expires_at}]
```

Команды:

- `village_quest_accept(id)`
- `village_quest_step(id, step)` — списывает товары атомарно, как `order`
- `village_quest_claim(id)`

Ограничения: лимит активных заданий 3, идемпотентность по `command_id`, rate limit — как у заказов.

Риск для баланса: средний. Задания дублируют доход с доски заказов. Предложение — давать в основном репутацию и декор, а монеты ≤ 50% от равноценного заказа.

## 3. Строительство зданий деревни (предложение)

Образец — `home_projects` фермы: этапы, склад материалов, сдача в доме.

- Общий проект фермы: вклад всех игроков, прогресс общий.
- Личный «улучшить свой дом»: только свой вклад.

| Здание | Этапы | Что открывает |
|---|---|---|
| Трактир | фундамент → сруб → крыша | Новые заказы «на ужин», быстрый переход к рецептам кухни |
| Оранжерея | рама → стекло → грядки | Зимние посадки (новый рецепт или культура) |
| Ярмарка | шатры → прилавки | Сезонная ярмарка: обмен с гостями |
| Кузня (уже нарисована) | — | Подсказки по инструментам и бонусы трактора (только информационно) |
| Рыбацкая хижина | мостки → хижина | Заказы Рыбака Сома |
| Школа / библиотека | книги → парты | Энциклопедия находок, вопросы Филиныча |
| Колодец, мост | один этап | Декор + короткий путь по карте |

На карте у каждого этапа своя картинка: «стройплощадка» (сейчас), «леса», «готово». Её даёт отдельный слой поверх `village.svg`, без перерисовки всей карты.

Данные: `village_projects: {id: {stage, store:{item:n}, goal_by_stage:[...]}}`. Команды: `village_project_contribute(id, item, n)`, `village_project_advance(id)`.

Риск: высокий — это сток товаров и долгосрочная цель. Нужны цифры от Ильи.

## 4. Разные действия в деревне (предложение)

| Действие | Что нужно | Риск |
|---|---|---|
| Поговорить | Клиентский текст по уровню репутации (уже есть: `VILLAGE_VOICES`) | Нет |
| Угостить / подарить | Новая команда `village_gift(npc, item)` → +репутация, лимит раз в день | Средний |
| Помочь по хозяйству | Мини-игры, которые уже есть (вопрос Филиныча, мешки) с наградой репутацией | Средний |
| Поручение-гонец | Взять посылку у A, отнести B: шаги `visit` в заданиях (раздел 2) | Низкий |
| Ярмарка / праздник сезона | Расширение текущего праздника: этап 4 открывает ярмарку на день | Средний |
| Купить в лавке | Лавка гостя-торговца: обмен по фиксированному курсу | Высокий (инфляция) |
| Письмо соседу | Через существующих «Соседей»: короткие готовые открытки | Низкий |

## Порядок внедрения (предложение)

1. Гости через серверное расписание (раздел 1). Без наград, только реплики.
2. `village_gift` и репутация.
3. Задания (раздел 2) с наградой репутацией.
4. Общие стройки (раздел 3), начиная с Трактира.
