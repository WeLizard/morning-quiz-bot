# Цирк — визуальная библия

Для ведущего и для новой графики: как герои и места выглядят **на готовом арте**
(`art_batch2/circus_lithograph`). Стиль `circus_lithograph`: старая цирковая литография-афиша,
красно-белые полосы, тёмно-синий и горчично-золотой, тёплая бумага, чёткий контур.

Ведущий описывает то, что игрок видит на портрете текущей партии. Отметка **⚠** значит, что портрет
расходится с каноном (`circus.md`, §3) по полу или возрасту; канонный облик нужно доделать вторым вариантом
(`NIGHT_CASE_OWNER_DIRECTION.md` §8).

## Места

У каждого места четыре версии по времени суток. Арт — вертикальная афишная картинка.

| id | Что видно |
| --- | --- |
| `animal_pens` | Загоны под полосатыми навесами, сено, ящики, дальше шатры |
| `backstage_wagons` | Двор за шатром: красные фургоны, сундуки, флажки над головой |
| `costume_tent` | Костюмерная: вешалки с нарядами, зеркало, сундук, маска на стуле |
| `director_wagon` | Красный резной фургон директора со ступенями, бочки и сено |
| `fortune_tent` | Полосатый шатёр гадалки с флажком, фонарь, колесо телеги |
| `main_arena` | Пустой манеж под полосатым куполом, ряды скамей, тумба посередине |
| `ticket_booth` | Будка кассы с окошком, афиши, ограждение у входа в шатёр |
| `town_square` | Мощёная площадь городка с ратушей, вывеской и колодцем, вдали шатры |
