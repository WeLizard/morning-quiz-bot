# Night City executable core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Исполнимый mini-case через чистые правила, пригодные для последующего V4 и «Усадьбы».

**Architecture:** Новый v2-контент и строгий state codec; один переход для игры и симуляции. Правила, чистые часы и адресные проекции отделены от БД и транспорта. Существующий v1 не меняет семантику и не запускается как игра.

**Tech Stack:** Python 3.13, stdlib dataclasses/zoneinfo/JSON, уже закреплённый jsonschema; unittest без БД.

**Spec:** [EXECUTABLE_FORMAT_V2](EXECUTABLE_FORMAT_V2.md), независимо проверен Sol после исправлений архитектором; [runtime](../NIGHT_CITY_RUNTIME_CONTRACT.md) согласован владельцем.

## Global Constraints

- Числа и приоритеты — точный rules snapshot из §8 спецификации. Общий простой сохраняет PC.
- No eval, provider, IO в переходе, DB/HTTP/Telegram в домене; неизвестные op/module/schema fail closed.
- Не присваивать полный KernelState в Game.state/HTTP. Source/private events и truth остаются закрытыми.
- Проверенные чистые правила не доказывают PG-гонки, перезапуск сервиса или готовность UI/rehearsal.
- Реализация в текущем dev checkout; чужие изменения и текущие старые партии сохраняются.

## Review Focus

- Равная разрешённая проекция при разных hidden variants даёт одинаковое меню/ошибки — engine/projection canary-тест.
- Actor A действует без invalidation actor B; timer_seq не равен player window_seq — engine fence-тест.
- Codec restore сохраняет private results/replay и не меняет типы JSON — state round-trip/negative fixtures.
- DST и 30-часовой outage не перематывают AFK/голосования задним числом — time/engine tests.
- Idle6 на последнем окне завершает unresolved, а не создаёт окно15 — terminal/freeze boundary test.
