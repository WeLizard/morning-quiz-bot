# ADR-003 — Отдельная сессия локального администратора

- **Статус:** `accepted` (локальная реализация)
- **Дата:** 2026-08-30
- **Задача:** [MQB-001](../tasks/MQB-001-postgresql-and-mini-app-foundation.md)

## Контекст

Существующая FastAPI-панель не имела входа. Ограничение адреса сервера само
по себе не защищает изменяющие запросы из браузера. При добавлении Mini App
административные права нельзя выводить из пользовательского Telegram initData.

## Решение

Отдельный случайный ADMIN_ACCESS_TOKEN обменивается на непрозрачную серверную
сессию. Она имеет HttpOnly/SameSite cookie, CSRF-токен, сроки и отзыв. Host/Origin
проверяются независимо. HTTP допускается только по loopback; остальные адреса
требуют HTTPS и явного allowlist. Без настроенного ключа доступ закрыт.

Сессии пока живут в памяти одного процесса: перезапуск отзывает их, несколько
workers не поддерживаются. Это один доверенный локальный администратор,
не многопользовательская система ролей. Полный IdP/OIDC сейчас не вводится.
Basic Auth отвергнут из-за неудобного отзыва/выхода в браузере; Telegram-вход
не объединяется с будущими пользовательскими правами Mini App.

## Последствия

Вход обязателен и для старых JSON-маршрутов. Перед локальным запуском нужно
задать отдельный ключ. Для PG-панели применяются local-only scripts и CSP;
legacy UI ещё требует проверки и переработки. Пароль администратора, аккаунты,
MFA, журнал персональных действий и distributed session store не добавлены.
Production не меняется; публикация панели в интернет не разрешается этим ADR.
