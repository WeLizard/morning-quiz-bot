# WeLizard Noir — Regular (v1.000)

Настоящий цифровой шрифт на основе предоставленного авторского SVG (контурной векторной таблицы знаков).

## Готовые файлы

- `desktop/WeLizardNoir-Regular.ttf` — TrueType, установка в Windows, Linux и других системах.
- `desktop/WeLizardNoir-Regular.otf` — OpenType/CFF, альтернативный формат установки.
- `web/WeLizardNoir-Regular.woff2` — основной формат для сайта.
- `web/WeLizardNoir-Regular.woff` — запасной веб-формат.
- `web/welizard-noir.css` — готовое правило `@font-face`.
- `web/demo.html` — интерактивный просмотр RU/EN в браузере.
- `proof/` — примеры набора, таблица глифов `glyph-index.json`, тесты.
- `sources/original-character-set.svg` — оригинальная авторская векторная таблица.
- `build_font.py` — скрипт воспроизводимой сборки из SVG.

## Как установить на Windows

Откройте **один** файл: `.ttf` **или** `.otf`, нажмите «Установить» или «Установить для всех пользователей». Не ставьте оба одновременно: это одно и то же начертание под одинаковым именем семейства.

**Семейство:** WeLizard Noir. **Начертание:** Regular.

## Как подключить к сайту

Перенесите `.woff2`, `.woff`, `welizard-noir.css` в одну папку сайта и добавьте:

```html
<link rel="stylesheet" href="/fonts/welizard-noir.css">
<h1 class="welizard-noir">ТАЙНОЕ ДЕЛО № 0192</h1>
```

Либо используйте в CSS `font-family: 'WeLizard Noir', Georgia, serif;`.

Файл `web/demo.html` открывается в браузере без внешних зависимостей.

## Состав и ограничения

- **274 Unicode-символа**, без служебного `.notdef`, в том числе 52 латинских, 66 русских букв с Ёё, 10 цифр, несколько десятков знаков препинания, валют, математических символов и орнаментов. Список — `proof/glyph-index.json`.
- Оригинальная форма глифов сохранена из векторных объектов SVG, включая кривые, отдельные точки и повёрнутые контуры Illustrator. Массовой перерисовки по пикселям нет.
- Это **одно** настоящее начертание **Regular**, то есть заголовочный шрифт. Bold и Italic не создавались искусственно: они потребуют отдельной корректировки штрихов/контуров и проверки. Шрифты для мелкого интерфейсного текста и моноширинный — отдельные семейства, не выводимые автоматически из этой таблицы с сохранением читабельности.
- Рисунки знаков не сопровождались исходными дизайнерскими данными о метриках и кернинге; расстояния, базовые линии и масштаб подобраны по расположению на листе. Перед промышленным релизом рекомендуется проверить пары букв в игре и при необходимости сделать дополнительную ручную подгонку метрик.
- `font-embedding` разрешён технически (`OS/2.fsType=0`). Использовать в собственном проекте по правам владельца исходного рисунка.
