# 📋 CHANGELOG — Morning Quiz

## 2026-09-04 — Общий Photo lifecycle для Telegram и Mini App

- Фото-загадки перенесены из `quiz_sessions` и in-memory Telegram timers в
  `games`, чистую state machine и серверные PostgreSQL deadlines.
- Mini App напрямую запускает серию, загружает защищённое изображение, отправляет
  текстовый ответ и завершает игру; MiniBridge для этих действий не нужен.
- Telegram использует те же команды и состояние; фото, подсказки и результаты
  публикуются через транзакционный outbox.
- Alembic 0011 сохраняет активные Photo-серии, прогресс и очки при переносе.
- Контейнерный gate: **444 passed**, Alembic upgrade/check и dump/restore.

## 2026-09-04 — Общий Classic lifecycle для Telegram и Mini App

- Classic перенесён из `quiz_sessions`/`BotState` в общий `games` lifecycle с
  чистой state machine, application service и серверными дедлайнами.
- Mini App запускает, синхронизирует, отвечает и завершает квиз напрямую, без
  поддельного `telegram.Update`; Telegram использует то же состояние и ledger.
- Alembic 0010 переносит старые Classic snapshots, ответы, poll ID и deadlines;
  добавлена отдельная таблица delivery bindings и защита от слепых повторов.
- Поддержаны актуальные `correct_option_ids`, `allows_revoting`,
  `shuffle_options` и обязательные `option_persistent_ids` Telegram Bot API.
- Dev-стек пересобран без сброса данных. Alembic head `20260904_0010`, HTTP smoke
  пройден, контейнерный gate: **442 passed**.
