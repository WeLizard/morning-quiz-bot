# Макеты: недельное дело «Хозяин исчез из запертой библиотеки»

Статус: на согласовании у владельца (2026-11-21). После согласования экраны переносятся
в `web/mini_client/night-case-ui.js`, а новые части стиля из `mock.css` — в `night-case.css`.

Зачем: экраны недельного дела сейчас — столбики текста и кнопок. Владелец решил, что экраны
игры должны быть с изображениями, как макеты первой версии (решения — в
`docs/tasks/night_city/NIGHT_CITY_MENU_DESIGN.md`, §7). Эти макеты показывают то же дело
на его собственных картинках: места — картинкой по времени суток, герои — портретами,
роль — картой в рамке, улики — предметами в рамках, слушание — портретами.

## Экраны

1. Ночной город — обложка, твои дела, вход по приглашению, открытые сборы, твои компании.
2. Новое дело — миры картинками (у готового мира — число дел, остальные «дела пишутся»).
3. Дело мира — обложка дела, действующие лица портретами (кого ведёт игра — отдельно),
   как идёт дело.
4. Сбор — места за столом портретами: сначала персонаж, игрок — плашкой («ты», имя игрока,
   «ведёт игра»); у места подпись «2 персонажа»; ведущий, часовой пояс, обсуждение.
5. Выбор персонажа — два персонажа одного места портретами, имя и возраст под портретом,
   «Любой из двух» или «Сесть: …».
6. Твоя роль — портрет в рамке, знак стороны (сторону задаёт вариант правды), тайна и цель.
7. Место — картина места по времени суток, слово ведущего, кто рядом, куда пойти,
   что осмотреть, записка, «Завершить окно»; выбор подтверждается в нижней панели.
8. Разговор — портрет собеседника, его реплика, действие окна.
9. Гостиная у камина — неделя по дням, итог окна от ведущего, опубликованные улики,
   записи игроков, поле реплики.
10. Улики — доска дела (опубликованное) и твои находки (видишь только ты).
11. Досье — кто ты, цель, тайна, записки, твои события по окнам.
12. Слушание — кто кого обвиняет портретами, приложенные улики, голос.
13. Итоговое слушание — подозреваемые портретами, улики к голосу.
14. Дело закрыто — картина развязки, твой итог, итоговое слушание, кто был кем
    (персонаж первым, игрок плашкой).

Состояния дела (отдельные листы `overview_states_*.webp`):

15. Отстранён — стол по ошибке отстранил персонажа на слушании (в правилах — «призрак»).
    Портрет своего персонажа приглушён, без привидений: в «Усадьбе» мистики нет. Что осталось,
    одно действие за окно, чат отстранённых. В игре с 2026-11-21 сделаны все четыре действия:
    воспоминание на доску, лично одному игроку, ответ «да/нет» на вопрос; «Явление» — только
    в делах с мистикой, в «Усадьбе» его нет. Пометки «из дизайна недели» на макете устарели.
16. Стол на паузе — шесть окон подряд никто не заходил; первый «Я здесь» открывает окно.
17. Ответ не дошёл — запрос не подтверждён, «Повторить» не спишет действие дважды.
18. Дело не открылось — нет связи совсем.
19. Меню ⚙ — компонент оболочки `QW.menu`: аккаунт, блок «Ночной город» (до 6 пунктов), блок ядра.
    «Музыка» и «Контрастный режим» — предложение: в деле недели их пока нет.
20. Своими словами — с ведущим-ИИ: игрок пишет, ведущий подбирает действие из доступных.
21. Запрос в архив — четыре копии из дела, ответ в следующем окне.
22. Архив версий — редакции завещания и три версии стола из дела.
23. Письмо — дворецкий возвращает Дочери закрытое письмо (экран другого игрока).

Новые предметы (часы, телефон, звонок, картотека, редакции, письмо на подносе, стул, перо,
свеча) — один прозрачный лист GPT Image 2026-11-21, нарезан на `art/*.webp`. Исходники,
промпт и нарезка — `docs/tasks/night_city/art_batch2/noir_print_a/items_states/` (вне git).

Слова на экранах: игрок выбирает **персонажа** (не «облик»). В коде и формате дела
это по-прежнему `looks`.

Тексты взяты из дела (`content/night_city/manor_lake.case.json`). Имена игроков (Вера, Олег…),
счёт голосов и время — примеры. Имён у персонажей в деле ещё нет (формат их поддерживает,
`looks[].name`): на экране выбора стоят примеры из решения П6 — «Пётр Ильич, 60» и «Агафья, 45»;
на остальных экранах карточка показывает название роли. Когда автор впишет имена, имя встанет
первой строкой, роль — второй.

## Сверка с живой игрой (2026-11-21)

Прошла партию целиком на локальном стенде: четыре игрока, окна 1–14, слушание с ошибочным
отстранением, вопрос отстранённому и ответ, выход из дела, туман, стол на паузе, итоговое
слушание, развязка, потеря связи. Снимки телефона 390 — вне git, у стенда
(`.local/night-case-ghost-stand/`).

Главное: в игре нет ни одного экрана из этих макетов. Игра показывает картину места и картину
развязки, всё остальное — текст и кнопки. Портретов нет нигде (за столом — значок вместо лица),
нет карты роли, нет предметов у улик, слушание не показывает, кто кого обвиняет, развязка не
показывает «кто был кем» и личный итог. Это не поломка: перенос макетов ждёт согласования.

Решение владельца (2026-11-21) для переноса: портрет выбывшего меняется по причине. Отстранён
на слушании — портрет затемнён. Убит (в делах, где смерть возможна) — полупрозрачный, с эффектом.
В «Усадьбе» смерти нет, есть только отстранение.

Найдено по ходу (не исправлено, кроме отмеченного):

1. Сбор: «На любом свободном месте: ты, seat02, seat03» — служебные номера мест вместо имён.
2. Часы окна: «832:05» — минуты и секунды при 13 часах до конца окна.
3. Обвинённый видит «Идёт слушание» без слов, кто обвинён и кем; может поддержать обвинение
   против себя.
4. После «Завершить окно» действия остаются кнопками.
5. После осмотра на «Месте» не видно, что найдено: находка появляется только в «Уликах».
6. Отстранённый остаётся в списке «Кто рядом» у живых.
7. Вышедший из дела видит «Доступные действия» и «Можно перейти в другое место».
8. Стол на паузе: две кнопки «Я здесь» на одном экране.
9. Ответ не дошёл: две плашки об ошибке сразу.
10. Обращение «Она» из сбора не действует: тексты идут по полу персонажа («Ты завершил окно»
    у игрока, выбравшего «Она», за адвоката-мужчину). Нужно решение, по кому склонять.
11. Отстранённый не видел причины и думал, что площадь ему закрыта — исправлено (`4079087`):
    на его экране слушание, которое его отстранило, и строка «Площадь ты по-прежнему читаешь».
12. Воспоминание, которое игрок сам выложил на доску до отстранения, предлагалось выложить
    ещё раз — исправлено там же.

Не проверено на стенде: «Своими словами» (нужен ведущий-ИИ), письмо дворецкого (экран 23).

## Как открыть и пересъёмка

```powershell
python docs/design/mockups/night-case/serve.py
```

Откроется адрес `http://127.0.0.1:4190/mock/index.html` — список экранов, у каждого есть
контрастный вариант. Сервер отдаёт файлы по тем же адресам `/app/...`, что и приложение,
поэтому макеты подключают настоящие `qw-tokens.css`, `qw-shell.css`, `night-city.css`
и `night-case.css` и картинки пакета дела.

```powershell
python docs/design/mockups/night-case/shoot.py F:\Temp\mqb-nc-mock\frames
```

Снимает кадры (телефон 360/390, планшет 768, ПК 1280, контраст), проверяет раскладку
(касание ≥ 44 px, зазор между кнопками ≥ 8 px, нет горизонтальной прокрутки, шрифт ≥ 12 px,
контраст текста на плашках ≥ 4.5) и пишет сюда `checks.json` (пусто — замечаний нет)
и обзорные листы `overview_*.webp`. Нужны Playwright и Pillow.
