# Макеты: недельное дело «Хозяин исчез из запертой библиотеки»

Статус: на согласовании у владельца (2026-11-21). После согласования экраны переносятся
в `web/mini_client/night-case-ui.js`, а новые части стиля из `mock.css` — в `night-case.css`.

Зачем: экраны недельного дела сейчас — столбики текста и кнопок. Владелец решил, что экраны
игры должны быть с изображениями, как макеты первой версии (решения — в
`docs/tasks/night_city/NIGHT_CITY_MENU_DESIGN.md`, §7). Эти макеты показывают то же дело
на его собственных картинках: места — картинкой по времени суток, герои — портретами,
роль — картой в рамке, улики — предметами в рамках, слушание — портретами.

## Экраны

1. Дело недели — обложка, стол, как идёт дело.
2. Сбор: выбор героя (портреты, игрок — плашкой на портрете) и выбор облика.
3. Твоя роль — портрет в рамке героя, знак стороны, тайна и цель.
4. Место — картина места, действия окна, кто рядом, куда пойти (соседние места картинками),
   что осмотреть (предметы); выбор подтверждается в нижней панели.
5. Досье. 6. Улики (доска дела и твои находки). 7. Беседа. 8. Хроника (неделя по окнам).
9. Итоговое слушание — подозреваемые портретами, улики к голосу картинками.
10. Дело закрыто — картина развязки, итог, кто был кем.

Тексты взяты из дела (`content/night_city/manor_lake.case.json`). Имена игроков (Вера, Олег…)
и счёт голосов — примеры. Имён у обликов в деле ещё нет: карточка героя показывает название
роли; когда имена появятся, имя встанет первой строкой, роль — второй.

## Как открыть и пересъёмка

```powershell
python docs/design/mockups/night-case/serve.py
```

Откроется адрес `http://127.0.0.1:4190/mock/index.html` — список экранов, у каждого есть
контрастный вариант. Сервер отдаёт файлы по тем же адресам `/app/...`, что и приложение,
поэтому макеты подключают настоящие `qw-tokens.css`, `qw-shell.css`, `night-city.css`
и `night-case.css` и картинки пакета дела.

```powershell
python docs/design/mockups/night-case/shoot.py F:\Temp\mqb-nc-mock\frames
```

Снимает кадры (телефон 360/390, планшет 768, ПК 1280, контраст), проверяет раскладку
(касание ≥ 44 px, зазор между кнопками ≥ 8 px, нет горизонтальной прокрутки, шрифт ≥ 12 px,
контраст текста на плашках ≥ 4.5) и пишет сюда `checks.json` (пусто — замечаний нет)
и обзорные листы `overview_*.webp`. Нужны Playwright и Pillow.
