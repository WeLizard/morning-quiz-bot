## Ответы владельца (2026-10-21)

1. Мельница: тестировщица в песочнице ставит обработку, возвращается — в мельнице пусто. Это баг пропажи задания/продукта, а не баланс опыта.
2. Данные тестировщицы в песочнице можно читать для диагностики.
3. Обоз: тестировщица сдала **все** предметы, обоз уехал, оплаты не было вообще — баг выплаты, а не «оплата за последний ящик».
4. «Забыть рецепт»: забывается только последний рецепт; непонятно, что происходит, если в очереди три разных. Нужно продумать поведение для очереди.
5. Текстиль: нужна вся цепочка (овцы → прялка → ткацкий станок → ткани/изделия, позже фабрики).
6. Алкоголь допустим: Telegram — лишь один из адаптеров. Делать с юмором — «0%», абсурдные напитки.
7. (2026-10-22) Память мастерской = последняя ручная постановка, а не накопленная история: если в очереди не осталось ручных партий, следующая ручная постановка начинает новый список; пока ручная партия в очереди, рецепты добавляются.
