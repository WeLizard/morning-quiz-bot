# MQB-004 — «Ночной город»: игровая вертикаль мафии

- **Статус:** `in_progress`
- **Приоритет:** high
- **Среда:** только локальная dev-копия

## Цель

Добавить отдельный режим скрытых ролей в общем стиле Morning Quiz. Это не
перекраска квиза: мафия получает собственное состояние, лобби, роли и позже —
групповой ход игры.

## Уже сделано

- [x] Экран «Ночной город» в Mini App с детективным вариантом ведущего.
- [x] Сохраняемый приватный черновик стола: 4–12 игроков, состав ролей и
  защита от перезаписи устаревшей вкладкой.
- [x] Состав рассчитывается сервером: мафия, мирные, детектив от 5 игроков,
  доктор от 7 игроков.
- [x] Черновик не изменяет баллы, сессии и правила классического квиза.
- [x] Групповое dev-лобби: создать/войти, увидеть готовность участников и
  защититься от устаревшего действия. Открыто только участникам чата.
- [x] Старт готового стола от четырёх игроков: сервер перемешивает роли, а
  Mini App отдаёт каждому только его собственную роль.
- [x] Общий `MafiaApplicationService`: HTTP и Telegram не рассчитывают роли и
  не записывают состояние самостоятельно.
- [x] Telegram-адаптер `/mafia`: создать стол, войти, отметить готовность,
  запустить ночь и получить тайную карточку роли/действия в личке.
- [x] Групповая карточка не содержит ID и распределение ролей; Mini App получает
  только адресную проекцию. Конфликты revision одинаковы в обоих интерфейсах.
- [x] Поддержан официальный direct link Main Mini App с `startapp`, который
  выбирает тот же групповой стол. Обычная `web_app`-кнопка в группе не используется.
- [x] Ночь, действия мафии/доктора/детектива, дневное обсуждение, личное
  голосование, выбывание и определение победителя работают через общее ядро.
- [x] Каждая активная фаза имеет долговечный дедлайн. Фоновая задача переводит
  просроченный стол дальше и после рестарта; Mini App обновляет состояние сам.
- [x] История партии не раскрывает роли, проверка детектива адресная, мёртвые
  игроки не действуют. После финала ведущий может собрать реванш тем же составом.
- [x] Telegram и Mini App используют одни команды/ревизии; групповой экран не
  содержит тайных целей. Мафия не начисляет очки классического рейтинга.
