# Alchemia · доводочная сборка 5.1

Это развитие ветки Alchemia до 421 элемента, а не очередное добавление названий. Все прежние открытия и 807 старых пар сохранены. База расширена до 1015 рецептов, точные повторы иллюстраций заменены, появились оформленные мастерские и экспедиции с состояниями этапов.

## Запуск

Откройте `index.html` в обычном браузере. В корне общего архива тот же файл называется `Alchemia.html`. Установка и интернет для самой игры не нужны. Для игры на компьютере Python не требуется.

На телефоне предпросмотр файла внутри файлового менеджера может не выполнять JavaScript. В таком случае откройте игру в браузере через локальный сервер. `START_WINDOWS.cmd` запускает `serve.py`, для этого способа нужен Python 3.9+. Сервер раздаёт только игру, не содержимое папки. Используйте его только в доверенной домашней сети; не публикуйте порт в интернете. Остановка — Ctrl+C.

## Перенос из первой версии

Самый надёжный способ: в старой Alchemia открыть «Настройки → Сохранить файлом». В новой — «Настройки → Загрузить файл», выбрать этот JSON и подтвердить замену.

Новая игра проверяет старые ключи `alchemia.atlas.v1` ... `v5`, а также список открытий исходной классической игры. Если нового сохранения ещё нет, доступные старые коллекции объединяются без удаления старых записей. Автоматический перенос возможен только при доступе к тому же хранилищу браузера. Это не синхронизация между устройствами, браузерами или изолированными локальными файлами.

Постоянный ключ теперь `alchemia.atlas`; формат сохранения имеет схему 2. Номер релиза больше не меняет адрес сохранения. Корректное новое сохранение всегда имеет приоритет над старыми, в том числе после намеренного сброса. При автосохранении предыдущий исправный снимок записывается в `alchemia.atlas.backup`. Повреждённая основная запись блокируется от молчаливой перезаписи; восстановление и импорт доступны с подтверждением.

## Управление

Нажмите два элемента в коллекции для смешивания, либо перетащите одну карточку на другую. На телефоне коллекция прокручивается обычным жестом, на столе работает перетаскивание. Shift+клик или правая кнопка открывает сведения. Очистка и отмена меняют только стол, не коллекцию.

«Путешествия» открывают эпохи. Внутри эпохи можно выбрать мастерскую: меняются иллюстрированная заставка и палитра, но все элементы по-прежнему совместимы с общей базой рецептов. На телефоне путь доступен через «Истории».

В экспедициях — пять историй по четыре этапа. Для каждого этапа нужны открытия и хотя бы один записанный рецепт указанного результата. Одного импорта названий для экспериментальной части недостаточно. Награда выдаётся кнопкой «Завершить этап» только после выполнения условий и предыдущего этапа. Печать и 10 очков выдаются один раз. Это коллекционные награды, а не валюта для покупки подсказок. Все подсказки остаются бесплатными. Свободные эксперименты не блокируются.

## Состав исходников

- `data.json` — единственный источник элементов, рецептов, глав и этапов.
- `game.js` — состояние, смешивание, коллекция, диалоги, импорт/экспорт.
- `journey.js` — оформление эпох, этапы экспедиций, проверка и выдача наград. Подставляется при сборке в маркер внутри `game.js`.
- `build_art.py` и `detail_art.py` — рисунки и общие векторные примитивы.
- `art.svg` — собранная библиотека изображений. `illustrations/` — отдельные SVG.
- `art_gallery.html` — полная галерея со спойлерами названий и изображений.
- `verify_content.py` — структура графа, идентификаторы, достижимость, ссылки и точные повторы SVG.
- `build.py` — автономная воспроизводимая сборка.

Команды из этой папки:

```text
python build.py
python export_art.py
python verify_content.py
```

`build_data.py` оставлен как совместимая команда проверки. Он больше НЕ перезаписывает `data.json`. Чтение и запись текстовых файлов выполняются с явной UTF-8. Никакие сторонние пакеты для сборки или экспорта иллюстраций не нужны.

## Что проверено и что остаётся

Смотрите `QUALITY.md` в корне архива и `evidence/BROWSER_REPORT.json`. Проверки проведены на Linux в Chromium с тестовым хранилищем. Открытие `file://` и реальный localStorage не удалось проверить из-за политики браузера данного окружения. Физические Windows/телефоны, Safari, одновременная игра в нескольких вкладках и длительное человеческое прохождение не проверялись.

Плотность рецептов, понятность отдельных ассоциаций и темп поздней игры всё ещё требуют живого тестирования. Это тестовая сборка для такого прохождения, а не обещание идеального баланса. Успех структурных тестов не равен качеству всех игровых решений.

Иллюстрации — SVG-композиции с общими стилевыми мотивами. Проверка подтверждает отсутствие точных копий содержимого, но не означает 421 независимую ручную живописную работу. Рецепты и описания — игровая фантазия, не научные или практические инструкции.
