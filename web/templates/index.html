⏳ Проверка доступности Puter.js...
💡 Меньше токенов = меньше расход кредитов. Рекомендуется: 1024-4096
ℹ️ Информация:
Puter.js использует модель "User-Pays" - пользователь покрывает расходы на использование API. Для работы может потребоваться авторизация на puter.com.
🇷🇺 Использование Puter.js из России:
Возможные проблемы:
  • Регистрация может быть недоступна из-за региональных ограничений
  • Блокировки на уровне DNS/IP
  • Требования регистрации провайдера в России
Рекомендации:
  • Используйте Anthropic API или OpenRouter с вашим API ключом (рекомендуется)
  • Если нужен именно Puter.js: используйте VPN из поддерживаемой страны
  • Попробуйте развернуть Puter на своем VPS за границей
  • Используйте альтернативные DNS-резолверы (Cloudflare, Google)
⚠️ Важно: Использование VPN может быть ограничено законодательством РФ. Рекомендуется использовать официальные API (Anthropic, OpenRouter) с вашим ключом.
