# Алхимия · Мастерская миров

Готовая одиночная браузерная песочница на русском языке. 263 элемента, 400 точных неупорядоченных рецептов, 263 встроенные SVG-иллюстрации, 11 категорий, восемь глав и 16 достижений. Никаких внешних библиотек, аккаунтов или сетевых запросов.

## Запуск

Открой `dist/index.html` в браузере. Все необходимые ресурсы находятся внутри HTML. Для публикации достаточно разместить этот один файл на статическом веб-сервере. Игра не публиковалась автоматически: сервер и адрес сайта не создавались.

На телефоне используйте веб-браузер, а не просмотрщик исходного текста HTML. Интерфейс адаптивный: касания добавляют ингредиенты, а при уходе основного тигля за границу экрана появляется компактная панель смешивания. В режиме свободного стола поддерживаются перетаскивание пальцем и выбор двух карточек касаниями.

## Что внутри

- Тигель и свободный стол; бесконечные копии ингредиентов, одинаковые ингредиенты допускаются.
- Атлас с описаниями, изученными рецептами, категорией, пометкой финальных находок и историей первого пути к открытию.
- Восемь необязательных глав, цели и подсказки в три шага, выбирающие только доступные ингредиенты.
- Избранное, поиск, фильтры, сортировка, журнал последних 160 опытов, счётчики всех опытов.
- Автосохранение, импорт/экспорт JSON с подтверждением замены, отдельное подтверждение новой игры.
- Очистка и отмена затрагивают только рабочий стол. Открытия не отменяются.
- Тихие синтезированные звуки по желанию и отключаемая анимация с учётом системных предпочтений.

Рецепты — игровая условность. Это не справочник по химии и не инструкции для реальных опытов.

## Сохранение

Ключ новой игры: `alchemia-worlds-v1` в `localStorage`. При первом запуске учитывается старый ключ `elementAlchemyDiscovered`, если он доступен из того же браузерного контекста. Старый ключ не изменяется. Миграция не обещает автоматический перенос между устройствами, браузерами или разными адресами/местами открытия HTML.

Автосохранение локальное, не облачное. При запрете доступа к хранилищу игра продолжает работать и показывает предупреждение. Для резервной копии используйте JSON-экспорт. Импорт заменяет прогресс после подтверждения, а не объединяет коллекции. Поддерживается формат `app: "alchemia-worlds", version: 1`.

## Исходники и сборка

- `template.html` — разметка интерфейса и декоративная сцена.
- `styles.css` — desktop/mobile стили.
- `game.js` — игровой движок, интерфейс, ввод, подсказки и сохранение.
- `data.json` — элементы, описания, рецепты и главы.
- `illustrations.svg` — набор символов `art-<id>` для всех элементов.
- `build.py` — проверка целостности данных и сборка автономного HTML.
- `verification.json` — результаты проведённых проверок.

Для пересборки нужен Python 3.10 или новее, сторонних Python-пакетов нет:

```sh
python build.py
```

Результат: `dist/index.html`. Перед записью проверяются существование ингредиентов, уникальность пар, наличие иллюстраций и достижимость всех элементов. Добавляя контент, обновляйте количество глав/категорий в описательных текстах при изменении их структуры. Числа элементов и рецептов в игровой логике берутся из данных.

## Проверка версии 1.0

Пройдено 60 автоматизированных проверок в Chromium, в том числе полный проход всех 400 рецептов через обработчики игрового интерфейса. Подтверждены все 263 открытия, восемь глав, 16 достижений; проверены обратный порядок и одинаковые ингредиенты, ошибки рецептов, избранное, поиск, атлас, подсказки, очистка и отмена, импорт/экспорт, восстановление сериализованного состояния, перетаскивание мышью и реальными touch-событиями в мобильной эмуляции. Проверены размеры от 320 px до 1920 px без горизонтального переполнения. Необработанных ошибок JavaScript в этих сценариях не было.

Ограничения проверки: отдельные испытания на физических телефонах, Safari и Firefox не проводились. Навигация браузера к локальным адресам в среде сборки была запрещена, поэтому тесты выполнялись через загрузку HTML в страницу; для сценариев сохранения использовался тестовый адаптер Storage с точным JSON round-trip. Этот адаптер **не входит в игровую сборку**: игра использует нативный `localStorage`. Отдельно проверена работа при отказе в доступе к хранилищу.

## Границы версии

В этой версии нет сервера, облака, мультиплеера, установки PWA и генерации новых рецептов нейросетью. Мир состоит из проверенного фиксированного набора рецептов, а маленькая панорама меняется по мере открытий. Все элементы доступны через цепочки от четырёх стихий: главами и достижениями ничего не блокируется.
